# Brainhole Engine Examples

## 哮天犬要离职

`brainhole_contract`:

- `one_sentence_sell`: 哮天犬不是背叛二郎神，而是向主角递交一份"忠诚岗位边界说明书"，要求把无限待命改成可考核的守护职责。
- `character_core_used`: 忠诚、嗅觉、守门、执行力。
- `modern_system`: 离职面谈、岗位职责、绩效考核、劳动边界。
- `contrast_mechanism`: 神话忠犬使用现代 HR 语言维护忠诚，笑点来自"越忠诚越要把职责写清楚"。
- `visible_comedy`: 它把"闻妖气"拆成 17 个 KPI，还要求夜班津贴用香火结算。
- `serious_underbelly`: 忠诚被无限透支后会失真，主角必须学会保护人才而不是消费人才。
- `plot_consequence`: 主角获得第一张神仙岗位卡，也暴露天庭组织治理失灵。
- `protagonist_decision`: opening 阶段只能做离职访谈和临时职责澄清，不能直接改天庭制度。
- `growth_stage_fit`: observe。
- `risk_check`: 不写成背叛二郎神；二郎神可以误会，但后续要圆回忠诚。
