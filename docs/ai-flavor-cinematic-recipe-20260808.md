# 画面感 / 去 AI 味配方（2026-08-08 固化）

八轮真机实验（MiniMax-M3，约 400 次调用）+ 人类语料定罪的结论。本文只记**已被证据支持**
的部分与**已知边界**；被证伪的做法也留档，避免重复踩。

## 1. 用户对「AI 味」的精确定义

| 病 | 例 | 为什么是病 |
|---|---|---|
| 结论先行 | 「不是敲，是拍」「正是师父惯用的暗号」 | 叙述者替读者下判断，跳过体验 |
| 状态描述冒充画面 | 「手腕发烫」「旧印泛起微红」 | 演员演不出来，读者脑中不成像 |
| 伪精确 | 「往前推半寸」「停了三秒」 | 具体≠量化；读者分不出半寸和一寸 |
| 否定式克制 | 「他没抬头」 | 没有画面，只有缺席 |
| 物件状态断裂 | 钥匙插死在锁孔里却「脱手落下」 | 不是一场戏，导演拍不出来 |

判据：**演员能不能照着演**。能演＝画面；不能演＝状态/判断/解说。

## 2. 人类语料基线（`.distillation_private`，2246 本，抽样 1427 章 / 4494 万字）

| 信号 | 人类中位 | 人类 p99 | 我们（修复前） |
|---|---|---|---|
| 状态词（发烫/泛红类）/千字 | **0.00** | 0.51 | 2.4–4.6 |
| 「他没X」/千字 | **0.00** | 0.18 | 0.6–1.0 |
| 动作+半寸/半分 | **0 命中 / 4494 万字** | — | 645/百万字 |
| 停顿+N秒 | 0.7/百万字 | — | 出现 |
| 台词占比 | **18%** | 57% | 0–7%（长期盲区） |

**必须豁免的人类正常写法**（词表误报老坑）：退一步 9.5/百万、敲了两下 7.0/百万、
半晌 14.6/百万、数息 25.2/百万、慢半拍（熟语）。

「烫」的真人形状：状态词只作「得」字动作链的引子——「烫得他摔了杯便连连甩手」，
**从不单独成拍**。AI 病不在词，在「状态词说完就收」。

## 3. 种词铁律（四次实证）

| # | 做法 | 结果 |
|---|---|---|
| 1 | 禁令点名「他没X」 | 该词出现 3 次（不禁时仅 1 次） |
| 2 | 禁「半寸」 | 变体「一寸」逃逸 |
| 3 | 枚举全部单位「寸尺步圈秒息拍下」 | 全部单位开花，违规翻倍 |
| 4 | 规则里写「不许写成冒烟」 | 「白烟」连出两轮 |

**铁律：prompt 层只许写「类别 + 正例」，任何具体 token 词表只属于检测器层。**
检测器不种词，prompt 会。

## 4. 生效配方（四层，缺一层都到不了 0 分）

### ① prompt 层（`config/cinematic_pov.yaml`）
- **说书人骨架**（原有，不可砍）：冷读者三问、因果可循、内心导航≥3–4 处
  —— 纯镜头流会杀掉「想表达什么」，2026-06 已翻车过一次
- **高光拍**（对峙/危险/刺激时刻才启用）：演员能演、感觉→第一反应动作、认出→动作证明
- **类别律**（本次新增红线）：幅度不量化（瞬时态或后果）、停顿用半晌/片刻、
  物件与双手状态全程连续、感官事实不加戏
- 整章另需：段落律（治单句独段）、直写律（治不是X是Y）、动词不复读、对白归属用动作牵

### ② 检测层（`data/ai_flavor/patterns_zh.json`）
本次新增 `pseudo_precision` 三规则（threshold=1，人类≈0）：
`cn.discourse.pseudo_precision_len` / `_time` / `_turn`，含豁免设计。
既有规则中整章高价值的：staccato_saturation、negated_definition、verb_tic_spam、terse_dialogue_tag。

### ③ 改写层（`services/deslop_revise.py`）
自查表新增第 13 条（伪精确 + 加字变体防护 + 误改防护）。
实测整章一轮改写：生产分 12→0、硬 tic 4→0、字数 1980→2031（不缩水）。

### ④ 人读兜底（不可省）
检测全绿后仍抓出：人称摇摆（妹妹喊「姐」而全文用「他」）、「站了几秒」（动词不在表）、
「指节**收得**发白」（加字逃逸）、改写引入的新 bug（捏一张还没递来的纸）。
**每处人读发现都要沉淀成新检测规则——这是检测器成长的唯一路径。**
**改写后必须复检**（改写会引入新 bug，已实证）。

## 5. 被证伪 / 不要再做的

- **真人范文 few-shot**：盲评 5/16 输给基线（语域与场景错位）
- **状态词「人类形状律」**（允许感觉词作引子）：5/16 输，判官更认全外化；
  「烫得甩手」连接式应留给检测器豁免，不写进 prompt
- **台词比例要求**（「占比 15–35%」）：模型只做到 7%，须改成拍点级指定
- **字数纪律写进 prompt**：四轮无效，只能门禁层收
- **LLM 场记查连贯性**：单票召回≈1/3，三票并集仍漏边缘案例；
  正解是分镜带「入镜/出镜状态」字段 + 确定性代码验状态链（场景卡 entry/exit 契约的既有形状）
- **LLM 判官**：对「分镜直译体」全盲（照判 69% 胜，人眼一读就是流水账）

## 6. 分镜两段式（可选增强）

先出 5–7 镜头表再写正文，盲评 11/16 胜。但必须配「分镜使用律」（主语明确、可合并镜头、
禁被动连用、拍摄词隔离），否则产出分镜直译体。成本 = 每高光拍多一次调用，只用于高光场景。
