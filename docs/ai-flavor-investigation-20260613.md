## 1. 调研：人类 / 榜单级中文网文的可验证写法机制

> 来源为实际访问到的英文 craft 资源、中文网文写作专区、两篇风格量化研究与中文 AI 味检测工具的公开维度（见文末）。阈值为工程推断，须在真实榜单语料上校准——**不是来源给出的硬数字**。

| 主题 | 人类 / 榜单写法 | AI 错法特征 | 可检测信号（建议阈值） |
|---|---|---|---|
| **句法节奏 / 段落切分** | 长短句交错的「呼吸感」；单句成段是**稀缺重击**（留白、爆点、信息延迟后的揭示），靠周围长段的反差获力 | 「匀速病」每段等长；staccato 滥用把叙述剁成大量单句独段；句长方差低 | 句长 CV ≥0.5 健康 / <0.35 预警；**非对话单句独段占比 >30% = HIGH**；连续短句 run ≥5 预警；叙述段句数中位数=1 强预警 |
| **微表情 / 微动作** | 具体可见动作＋与物件互动＋行为后果替代抽象身体反应；一个抖腿胜过「他很焦虑」 | 「瞳孔一缩/眼皮一跳/心头一紧/喉结滚动」成串、与场景无关、无后果；同情绪反复同模板 | 复合微动作模板命中 >每千字 1.5；同模板章内 ≥3 次判重；微动作句无物件/无后果占比 >60% |
| **心理递进 vs 结论先行** | Show 情绪的**发生过程**：感官→念头链→身体感受逐步逼近；信息延迟制造悬念 | 结论先行「这不是 X 而是 Y」「他知道，一切都变了」；顿悟模板「突然明白/瞬间懂了」 | 反对式公式「不是…而是…/与其说…不如说…」>每千字 1；顿悟宣告句首每章 >2；抽象情绪贴标无落地占比 >50% |
| **对白节奏 / 标签** | 标签以「说/道」为主（透明）；用**动作 beat 替代副词标签**；乒乓快打＋沉默留白 | 副词标签「冷冷地说」成串；**「单字情绪＋裸标签」**「『冷。』他说」密排；beat 缺失人物悬空 | 副词标签占比 >15%；**短台词＋裸标签连续 ≥3 处**；长对白场景 beat 覆盖率 <20% |
| **叙事视角 / 场景承接** | 紧贴单一 POV；切视角在场景断点；转场重置时间/地点/在场者锚点 | head-hopping 同场景乱跳内心；上帝点评「殊不知/命运的齿轮」；转场无锚点 | 同场景非 POV 角色名＋心理动词；上帝点评词每章 >1；转场首段无时空锚点 |
| **AI-slop 检测现状** | — | — | 最稳健且跨语言：**burstiness（句长 CV）**、TTR（词汇多样性）、连接词密度（中文高度有效）；**单一指标尤其裸困惑度不可靠，须多指标组合＋相对盲评**（与本项目 LitStyle 绝对分不可信结论一致） |

**关键方法论结论**：与本项目既有判断一致——**句法节奏病不是词汇病，词汇黑名单对结构性 AI 味全瞎**。所有规则做 soft 闸门加权，绝不用单分拍板；阈值须用真实榜单语料分位数校准。

## 3. 根因分析：框架在「教」模型写碎句

`anti_ai_voice` 锚点（commit 527840d）**已经**有 `over_fragmentation`/`abstract_verdict`/`nominalized_cool` 三条伪文学短句守卫，写手 prompt 确实在劝阻碎句。但 255 处独行短句仍在，原因有二，**互相叠加**：

1. **规则口径错位**：`over_fragmentation` 针对「**整段**剁成 3+ 短句」（段内）。模型的规避方式是把每个短句**单独成段**——更碎，却同时绕过 prompt 规则（它说"整段"）和 span 检测器（`cn.rhythm.choppy` 要求**段内 ≥3 句**才触发）。单句独段在评分上完全隐形。
2. **框架自相矛盾**：`rhythm_engineering` 把「一句话独段（≤10 字）」当 `hard_stop` **正向奖励**，`distribution_health` 还规定「≤15 字短段占比 30–50% 才健康」——**只有下限没有上限**。模型靠**最大化 hard_stop** 消解「既要锚点又别碎句」的矛盾，结果 ch12 出现 43 段单句独行，且大量以「他…」机械开头。

**验证**：全 18 章句长 CV 在 0.56–0.84（**全部健康**，远高于 0.35 低值线）——证明 staccato **不是句长方差问题**（句子有长有短），而是**段落结构问题**（太多拍点被孤立成独段）。因此 burstiness/CV 是错的量具，**单句独段占比**才是对的量具。

## 4. AI 味模式清单 + 反例 + 改写策略（按本书实测排序）

### 模式 ① 独行短句装腔 / 句式机械重复（255 处，主瓶颈）

- **病征**：长段 ↔ 单句独段交替；连续多句以同一主语（多为「他」）开头。读起来像分镜脚本。
- **真实样本（本框架自产 · ch12）**：…长段… → `谢迟的心一沉。` → …长段… → `他没有第二条路。` → `他没带笔杆。` → `他只带了砚。` → …（「他…」机械重复）
- **反例（healthy）**：单句独段是**稀缺重击**（如孤零零一句 `齐了。` 收束一段铺陈），不是每隔一两段就甩一个。
- **改写策略**：把**机械的**一行句折回相邻段落，用长短交错、保留主语、变化句首的完整句写完整；**只**保留真正承担重击/留白功能的那一两句；连续同主语开头打散。
- **改写样例（评分实测）**：

  | 版本 | detector 评分 | 命中规则 |
  |---|---|---|
  | BEFORE（12 句独行 +「他」机械开头） | **4.0** | `staccato_saturation` |
  | AFTER（折回 3 个长短交错段、变化开头、保留 1 个重击「没有第二条路了」） | **0.0** | 无 |

  > BEFORE/AFTER 为本报告自撰演示文本（非复制），完整内容见 `scripts/ai_flavor_diagnose.py` 配套与 git 提交说明。

### 模式 ② 复合微动作模板（17 处）→ R2

- **病征**：`[人]的[身体部位][微动作]了一下`（瞳孔缩了一下 / 心一沉 / 眉心一皱 / 眼皮掀了一下又合上），与场景物件无关、无后果。
- **改写策略**：换成具体可见动作＋与物件互动＋行为后果；同章同模板 ≤2 次。

### 模式 ③ 终末裸对白标签「冷，他说」（本书少，框架风险）→ R2

- **病征**：单字/短情绪台词＋无 beat 的「X 说/道」连发。
- **改写策略**：副词/裸标签换动作 beat（先一个物理动作再台词）；连续 ≥3 处裸标签判模型腔。

### 模式 ④ 否定式下定义「不是 X，而是 Y」/ 结论先行 + 顿悟宣告（目标点名）→ R3（已落地）

- **病征**：叙述者先抛抽象判断替读者下结论；「这不是 X，而是 Y」「与其说…不如说…」「突然明白/忽然意识到/一切都变了」。
- **改写策略**：让读者自己得出结论；把判断落到感官/动作/物件，过程在前结论隐去；顿悟靠念头逐步逼近，不靠宣告。
- **本书实测**：`negated_definition` **0 命中**（无误报）；`epiphany_announcement` 仅 **ch4** 触发（该章过度依赖「忽然明白/忽然意识到」≥10 次，其余 17 章 ≤2 次未触发）——R3 把一个**此前评分隐形**的真实过度依赖浮了出来。
- **改写样例（评分实测）**：不是X而是Y **4.0 → 0.0**；顿悟宣告（3 连发）**8.0 → 0.0**。

- **R2 / R3 均已落地（见 §5）**。三轮聚焦修复完成。
- **未解风险（如实记录）**：
  - **治本在重新生成/改写时让 prompt 上限与 banned_patterns 生效**——本工作**未重跑整书**（重生成消耗付费模型额度，属暂停条件），故只验证了「检测能浮出问题」「prompt 已带上限/反例」「改写样例评分一致下降」，**未验证「下一次正常生成时命中率实际下降」**。需在下次跑书时观测 `staccato_saturation` / `body_micro_action` / `epiphany_announcement` 命中率。
  - 阈值（staccato 0.25/run5/subj3、各簇 threshold 3、terse ≤3 字 ×3）为单本书 + 研究推断，**须用更多真实榜单语料校准分位数**。
  - ch4 因 epiphany 过度依赖升到 48 分（仍 < 50 block），属真实信号；若后续内容叠加可能越线触发机器修复——这是期望行为，非缺陷。
  - burstiness/TTR/连接词密度、对白 beat 覆盖率、head-hopping/上帝点评、转场锚点等更稳健的多指标尚未接入（研究建议，超出本轮三轮最小修复范围，列为后续）。
  - 所有新规则均为 **soft warn / advisory**，不硬阻断、无 auto-patch（patcher 对无 suggestion 的 warn 自动跳过），因此对既有正文与导出零破坏。
