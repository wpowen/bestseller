## 一、开场重构的核心判断

v3 的黄金第1章《哮天犬要辞职》是好材料、错位置：它交付「暖+喜剧」，主角是旁观者。男频爽文第1章铁律是**主角先跌进泥里，再当众翻身**。v3 把主角反差弧线（被坑失业的HR→给神仙发offer）后置到第5章插叙，等于把最爽的牌焊死在抽屉里。

**v4 重排**：主角低谷与金手指觉醒提到第1章正面强攻；哮天犬辞职后移为第4章（入职后第一个诡异工单，喜剧单元启动+杨戬线信物交付）；原 ch2-3（土地公退休+暴雨封神）压缩为新 ch2-3，保留「爽泪同振」名场面。第5章倒叙背景的设计取消——背景已在 ch1 用冲突现场交代完。

**新增具名人物：周衡**（前东家HRD）。37人名单是他接手写的，陈屿的总监位是他坐的，三年前他剽窃过陈屿的未署名提案——把主角死穴（37人名单）从背景设定变成**第1章可打脸的活人**。后续：卷1末被白先生收编为人间代理人（缝合人间线与邪修猎头线），卷9作为证人席伏笔反转（他保存着当年名单的原始邮件）。

## 二、黄金三章细纲 v4（融合方法论格式）

> 每章五件套：目标情绪 / 章首钩子(7式选型) / 章尾钩子(13式选型+强度) / 爽点 / 新专有名词预算。

### 第1章《月薪八万，招的不是人》
- **目标情绪**：爽（憋屈→翻盘释放）
- **章首钩子**：反差场景式——失业第94天，第3个 offer 被背调取消
- **核心节拍**：低谷（背调被卡、"刺头"标签）→ 诡异JD（"识人。仅此一条"）→ 面试撞仇人周衡（踩主角：「失业也是一种休息」）→ 裁员题对决（周衡念成本模型 vs 陈屿翻出肿瘤科报销单：「人没有废的，只有放错的」）→ **识人面板当场觉醒**（老金头顶【太白金星·信力余额见底】+周衡头顶【命格：窃】）→ 错别字打脸（「冗余」写成「荣誉」证剽窃，金手指给线索、HR专业定罪）→ 周衡出局 → 八万月薪 offer → 窗外外卖小哥头顶【赵小磊·土地神适配99%】
- **爽点**：当众揭穿剽窃（铺垫=三年憋屈+当面羞辱，释放=一个错别字定罪）
- **章尾钩子**：突然揭示式（强）——工牌背面「第七任。前六任在职，平均十一天」+ 楼梯脚步声渐近
- **信息预算**（≤6）：三垣、识人面板、神职适配度、太白金星（老金）、offer、第七任。**信力/香火/司衡/灵山/道盟一概不许出现**
- 三基点核查：人设基点（因善被裁的HR+「放错位置」哲学）✅300字内登场；切入点基点（诡异公司面试）✅；金手指基点（面板觉醒+当场用出战果）✅

### 第2章《子时退休的神》
- **目标情绪**：好奇+紧张（悬疑主导，暖为底色）
- **章首钩子**：未完成动作式——赵小磊推门进来，外卖单收件人写的是「老街土地公（亡）」
- **核心节拍**：入职第一天，第一张工单=老街土地公子时退休、24小时内找到继任者 → 雨夜屋顶退休面谈（老神问「你一个凡人怎么干上这行的」，陈屿：「三个月前我连自己的工作都找不到」——一句吊背景，不展开）→ 面板扫街锁定赵小磊99% → 巷口情报战（赵小磊脱口说出十七户门牌细节 vs 周衡式候选人背的十二万合同）→ 章末毁档突袭：有人动了赵小磊的档案，99%跌到61%
- **爽点**：情报战碾压（外卖小哥的「土办法」当众压过精英简历）
- **章尾钩子**：紧急危机式（强）——适配度还在掉，子时只剩五小时
- **信息预算**（≤5）：工单、土地公、神职交接、适配度可变、档案（毁档黑手暂不露脸）

### 第3章《暴雨签字》
- **目标情绪**：燃+泪（爽泪同振，全卷第一个情绪峰）
- **章首钩子**：倒计时开局式——距子时还有三小时，雨没停
- **核心节拍**：对等告知毁档真相+陈屿以荐主身份连带作保（「offer我递，字你自己签」原则首次成文）→ 赵小磊冲进暴雨修7号院廊灯（「等灯亮了我就签」）→ **子时金光：廊灯亮、签字落、灰雾退散、老土地公散作漫天灯火落进每户窗台** → 封神成功
- **爽点**：签字即封神的权力首次完整兑现（金手指第二段能力「Offer即封神」亮相）
- **章尾钩子**：隐藏含义式三连（强）——①系统提示「月薪八万已调整为四千」（业绩越好职级越降的悖论首露）②老神最后一句「第七个了，希望你比前六个，眼睛干净」③对面巷子越野车引擎轰响
- **信息预算**（≤5）：Offer即封神、荐主连带、灰雾（只给画面不给术语解释）、职级反向调整、前六任

### 第4章《哮天犬要辞职》（v3 第1章平移+oh-story 版执行）
- **目标情绪**：轻喜+暖
- 正文以盲评 86 分的 oh-story 手写版为基准稿（output/_compare-ohstory/chapter-001-ohstory.md），仅做衔接改写：陈屿已入职数日、面板已熟用
- **章尾钩子**：神秘物品式（中强）——天眼徽章「等第七个人事来了，把这个交给他」（杨戬线启动）
- **信息预算**（≤5）：灵兽编制、信力（首次出现，借「犬粮信力」生活化引入）、杨戬、谛听年糕、姜子牙

## 四、全流程管线参数（v4 重跑卷一时生效）

1. **章纲生成**：planner 已注入情绪必填+钩子13式选型+黄金三章约束（工程项 A2），本表第二节就是目标产物形态。
2. **信息节流**：ch1-3 新专有名词预算 6/5/5，写入章纲 `chapter_information_introduced`，超预算项进 `held_back`。
3. **验收**：opening_golden_chapter_gate（A3，soft）+ 既有 opening_three_function_gate 双闸并行；缝合层节拍去重（A4）防高潮重演。
4. **基准稿复用**：ch4 直接以 oh-story 手写版为底稿进修订流，不走全新生成（已验证 86 分，没必要重掷骰子）。
5. **对标回归**：重跑后照常跑 fanqie_long_ranking 回归+跨家族判官盲评（--judge deepseek），与 v3 的 ch1-9 留档对比，量化 v4 增量。
