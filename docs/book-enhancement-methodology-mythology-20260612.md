# 《神仙都是我招的》增强计划：框架方法论 × 神话资源库

> 2026-06-12 · 规划线文档（与修复线 framework-design-quality-review-20260612.md 分离）
> 两个杠杆：①把框架已有但本书未用满的方法论资产逐项接上；②建立三层神话资源库，用"HR视角重读中国神话"作为本书独有的资源转化方式。

## 1. 框架方法论资产 → 本书应用清单

| 方法论资产 | 现状 | 应用动作 |
|---|---|---|
| story_design_grammars（urban-contemporary + eastern-aesthetic） | 未对账 | 用语法的 required_contracts/chapter_change_vectors/forbidden_defaults 对卷一50章做一次合规审计；天庭场景叠加 eastern-aesthetic 美学语法 |
| chapter_position_profiles（章节位置画像/敏感窗口反模式） | 未应用 | 给卷一标定位置画像：高潮位（ch3/15/23/30/41/45/48）、酝酿窗（ch5-6/16-17/31-34）、喘息窗（ch7-10）——避免全卷均速 |
| emotion_choreography（压抑→释放曲线+情绪标签禁令） | 部分生效（正文层） | 规划层显式标注每章情绪预算：泪点章（7/20/34）压抑相拉满，爽点章（3/23/45）释放相拉满；连续两章同相位即调整 |
| information_choreography（信息编排/每章硬指标/信念审计） | 未应用 | 建立暗线披露预算表：工牌"第七任"（ch1埋/ch5官方承认/ch37姜暮实名）、天眼徽章（ch1埋/ch8协议露名/卷4兑现）、前六任（ch6档案/ch44败因）——每章只许推进一格，禁跳格 |
| public_emotion_methodology（公共情绪锚/三桥接） | 未应用 | 每个案件绑定一个公共情绪锚：赵小磊=被平台困住的骑手、徐潮生=赡养与生计的撕扯、周渡=35岁被优化、张德顺=被遗忘的底层、嫦娥=夜班族、八戒=被人设绑架的内容创作者 |
| motif_library（母题组合规则） | 主母题已设 | 按组合规则给每卷分配子母题：卷一=代班与交还×平凡的正当性；卷四=被观看与被定义；卷六=记忆与遗忘 |
| hook_mechanisms + 钩子公式库 | 手写未分型 | 给50章尾钩标注类型并做轮换检查（悬念钩/反转钩/情感钩/危机钩），连续3章同型即改写 |
| character_engine 关系记忆库 | 主角已建 | 为新案件角色（徐潮生/周渡/张德顺）补 relationship_memory 与 evolution_trajectory |
| cultural_archetypes/classical_chinese（器物美学） | 自发使用 | 把已自发出现的器物系统（业力秤/判官笔/香炉打卡机/皂隶朱笔）正式登记为本书 palette，写手层强制复用 |
| material_library 场景库 | 玄幻库存在 | 新建"都市神话"场景模板批次（见§2神话资源转化） |

## 2. 神话资源库（三层版权安全策略）

| 层 | 资源 | 使用方式 |
|---|---|---|
| **T1 公版直接用** | 《封神演义》《西游记》、民间神谱（城隍/灶神/月老/龙王/土地）、《山海经》《搜神记》《聊斋》 | 角色、神职体系、典故直接演绎改写 |
| **T2 类型公约借形不借实** | 洪荒流公约概念（量劫/天道/圣人闭关） | 用信力经济学重新解释后使用（见§3） |
| **T3 现代作品只借期待形态** | 《佛本是道》《西游记后传》等 | 只借"读者期待"（翻案叙事、佛道张力），不借具体设定/角色/情节；过 copy_risk 闸门 |

## 3. "用HR视角重读中国神话"——典故人事化转化表（本书独有金矿）

| 神话典故 | 人事化重读 | 落点 |
|---|---|---|
| **封神大战** | 上一次"量劫"的组织重组——《封神演义》是本书的"公司前传史"，姜子牙=上一任执榜人事 | 卷5中点反转的史料层；老金的档案室藏着"封神项目复盘报告" |
| **量劫** | 司衡的周期性总清算审计——每个会计周期一次"大清算"，历史上的神仙大战都是清算季 | 卷8真相层：本书的总清算=新一轮量劫 |
| **弼马温** | 悟空的"职级羞辱"旧案：天庭史上最著名的错配——拿齐天大圣的人才当马场临时工 | 悟空拒绝offer的心结根源；陈屿的破局：当面重做一份迟到五百年的人才评估（卷9名场面） |
| **紧箍咒** | 旧时代的"强制竞业协议" | 悟空线的主题武器："你们管那叫管理，我管那叫戴刑具" |
| **蟠桃会** | 年度编制评审大会（蟠桃=绩效份额） | 卷5或卷8大型喜剧+权斗场面：陈屿第一次列席，发现份额分配公式一千年没更新 |
| **杨戬劈山救母** | 家人因旧制度受难的工伤家属——他拼命守岗是不想让制度再伤第二家人 | 杨戬深层动机；卷4-7人物厚度 |
| **哪吒闹海** | 史上最大未成年劳动争议+削骨还父=最惨烈的"离职清算" | 哪吒碎魂线的史料层；转世制度的判例引用 |
| **阿傩伽叶索人事** | 原典背书的"宗教中层腐败"先例 | 灵山香火宝暴雷卷的合规护栏+彩蛋 |

| **月老红线** | 上古的"匹配算法"——和识人面板同源技术 | 月老案（卷2-3单元）：红线库年久失修乱牵线 |

| **轮回/孟婆汤** | 离职安置+记忆合规（洗忆=数据删除权） | 孟拂线的制度纵深 |

## 4. 本书优化点清单（按落地顺序）

1. **卷2-10资产预排表**（最优先）：把IP角色/组织线/劫难/转职案/神话典故逐项分配到具体卷——对冲框架卷计划"资产蒸发"缺陷；卷二城隍断案卷立即受益（月老案/判官笔器物/孟拂制度纵深）
2. **蟠桃会编制评审大会**写入卷5（资本收购战的神界镜像——两场"位置拍卖会"对照）
3. **弼马温人才评估重做**定为卷9悟空回归的触发名场面
4. **量劫=清算审计**的lore写入卷8真相层（让司衡的威胁获得神话史纵深）
5. **暗线披露预算表**（§1信息编排）落到卷一逐章
6. **尾钩类型轮换表**对卷一50章做一次标注与调整
7. **公共情绪锚**写入每个案件的 premise 段（接框架 public_emotion 管线）
8. 器物 palette 登记+都市神话场景模板批次入库

## 5. 反推框架（与修复线对接）

本计划暴露的框架缺失（已并入修复线问题登记册）：
- 方法论资产大多只挂在**正文层**（写手/判官），**规划层不消费**——故事语法/位置画像/情绪编排在卷计划与章纲生成时不可见（修复线 P1-10）
- 无"资源库→规划"通道：T1公版神话资源没有结构化库（人物/典故/可用关系），规划时全凭模型记忆（修复线 P2-11）
