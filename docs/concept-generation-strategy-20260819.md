## 一、头部创意的五种诞生机制（外部调研，带源）

1. **阅读遗憾重铸**：乌贼自述《灭运图录》《奥术神座》都源自"别人高开低走的书重写成自己的版本"。
2. **前作内孵化**：《诡秘》=《一世之尊》里一个小世界+克苏鲁+维多利亚偏好——概念先在旧书低成本试跑。
3. **榜单反向定位**：肘子《大王饶命》=对主流"冷酷果断"人设做一轴反转；《十日终焉》把"不套路不爽文"当卖点绕开正面竞争。
4. **读者反馈回路**：老鹰吃小鸡靠读者指出重复；虫队把评论区的坑记备忘录逐一填。
5. **扫榜拆书+切书**：行业惯例=开书前逐段拆榜单书；数据扑了切书重开，"同概念换开头重试"是人肉多臂老虎机。

共性：**没有一种是规则清单驱动**（与内部证伪一致）；行业比我们多一层「开篇级重试」。

## 二、七条生成策略（S1-S7，含铁律取舍）

S1 遗憾重铸（高开低走书语料→机制骨架种子；须概念级查重先行）
S2 榜单反向定位（主流分布统计+恰一轴反转；反主流本身须进母题饱和检查）
S3 前作孵化台账（跨书候选概念库；防私货污染守卫）
S4 同概念开篇多臂（冠军概念先产N个开篇变体盲评选优；须确定性尺子+跨家族多采样）★最便宜增量
S5 锚书差分种子（求书帖"类似X但是Y"；X必须蒸成类别骨架防句法复印）
S6 负面承诺当卖点（不圣母/智商在线进概念与简介层；正文层必须转正向表述——否定式点名=种词定案）
S7 身份×制度错配句式判据（"死刑犯参加死亡高考"形态；上线前必须真爆款回测，只挣warn）
