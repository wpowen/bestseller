# 开发方案 · 上架资料 AI 味 / 债务复发 / 设定与逻辑（2026-08-24）

用户报三件事：①上架资料简介 AI 味重 ②书籍设定没用上、逻辑不通 ③债务母题反复出现。
本方案先给根因证据，再给修复项与执行顺序，最后是验收口径。

---

## 一、根因证据（真机，5 本书）

### P1 简介：文案工序跑了，上架资料不用它

| 字段 | 内容 | 判定 |
|---|---|---|
| `metadata.synopsis` | 「杂役弟子祝余刚被人当众借走全部真气……<br>他想收手，账本却自己翻到下一页——门外扔进来一只内门师兄的旧鞋，鞋里夹着欠条。」 | 短段落、有钩子，**这是文案工序的产出** |
| `promotional_brief.blurb` | 「青云宗杂役祝余天生一双能看见借债走向的眼睛……**第50章**，账本只剩最后几页」 | **premise 逐字复制**，剧情流水账，还报章号 |

- `copywriting_tournament` 在 5 本书上**全部跑过**，4 本 `fell_back_to_v0=false`（产出了冠军）。
- `_generate_promotional_brief` 的 source-bound 分支取的是
  `snapshot.reader_promise → book_spec.logline → fallback`，**从不读文案冠军**。
- ⚠️ 我第一次查「简介子系统有没有跑」时查的是 `projects.metadata`，回执其实在
  `conception_snapshot` 产物里，得出了「零痕迹」的错误结论。**查字段前先确认它住在哪张表。**

### P1.2 生产口吻检测器漏网

`copy_flavor.directive_voice` 要求「生产锚点 + 指令动词」同时命中：

| 真机文案 | 分数 | 漏网原因 |
|---|---|---|
| 「**第50章**，账本只剩最后几页」 | 0.0 | 有章号锚点，**没有指令动词** |
| 「**上一章**替他挡刀的人，**下一章**就得哭着求他还人情」 | 0.0 | 同上 |
| 「前几章给出……的反转节奏」 | 6.0 | 命中 |
| 「前五章让读者看到……**爽感**」 | 6.0 | 命中（动词表今日已补） |

**读者文案里出现章号本身就是生产口吻**，不该再要求配一个指令动词。

### P1.3 `reader_promise` 4 个非空里 3 个有生产口吻

`爽点`（14.0）、`前几章给出`（6.0）、`前五章让读者看到`（6.0）。
`爽点` 本就在 `trade_jargon` 词表里 → 说明**分数算出来了但没驱动重写**，需核查
`_brief_copy_flavour → _rewrite_flavoured_copy` 的接线是否覆盖 `reader_promise`。

### P2 债务：上架资料层没有独立的门

书9 的三个读者可见字段全部 `is_debt_dominated=True`：

```
简介      账+债 11 次 / 3 子族   支配
一句话     账+债  6 次 / 3 子族   支配
读者承诺    账+债  3 次 / 3 子族   支配
书名      《别人借力我替他们还债》
```

末日书（题材完全不同）的一句话与读者承诺同样 `支配`：
「用一根钢绳和一本**账本**，把整栋烂尾楼的人吊成他的客户、他的**债主**」。

构思终稿那道门量的是 **premise+synopsis+writing_profile 的整体 blob**，
**从不单独量「读者会看到的那三行」**；而这三行恰恰是用户唯一会看到的东西。

### P3 设定没用上 / 逻辑

- 「材料没拿」已确诊 6 例，其中 4 例**已修但未部署**（境界阶梯三格式、中文卷序、
  逐卷揭示、伏笔账本）。
- 概念级逻辑自相矛盾无确定性判据。真机样例（端到端书）：
  「器灵**就是天劫本身**，头顶雷云就是他的身体 …… 宿主一旦被劈死，器灵当场被抹除」
  —— 雷由他落、落了会杀死宿主、宿主死他也没了，那雷为什么还会落？
- `blurb_coherence_judge` 存在，但这 5 本书没有留下任何矛盾记录，需核查接线。

## 二、修复项

| # | 项 | 类型 | 风险 |
|---|---|---|---|
| **F0** | 部署已修的 4 条 | 部署 | 无 |
| **F1** | 上架资料改用文案工序的冠军简介 | 接线 | 中（改变对外文案来源） |
| **F2** | `copy_flavor` 新增「读者文案里报章号」规则 | 检测器 | 低（须人类语料校准） |
| **F3** | 核查并接通 `reader_promise` 的去行业词修复 | 接线 | 低 |
| **F4** | 上架资料层的默认族检查（只降权/重写，不发杀权） | 门 | 中 |
| **F5** | 核查 `blurb_coherence_judge` 接线；概念级逻辑矛盾判据 | 门 | 中 |
| **F6** | 跨章逐字段落重复：导出门已能抓到，让它真的拦住 | 门 | 中 |

**不做**：给 prompt 加「不要写账本」这类否定式指令。本仓库 2026-08-06 定过案：
**否定式指令点名母题词 = 种词**，会把它塞得更死。所有母题控制走检测+降权+重生成。

## 三、执行顺序与验收

1. **F0 部署** → 自愈扫描 3 轮无异常
2. **F1 → F2 → F3**（简介链，一次做完再测）→ 全量单测 + 人类语料误伤校准
3. **F4**（债务）→ 三本真书历史数据回放，确认对干净书零误伤
4. **F5 / F6** → 单测 + 真机
5. **部署 → 跑 1 本同参数新书（零种子 / minimal / 12 章）**

### 验收口径（写在跑书之前）

| 项 | 硬指标 |
|---|---|
| 上架资料简介 | 与 `premise` **不相同**；来源可追溯到文案冠军 |
| 简介/一句话/读者承诺 | `detect_copy_flavor` 全部 **0 分** |
| 读者可见三行 | `is_debt_dominated` 全部 **False**（用户未点名该族时） |
| 章号 | 三个读者可见字段里**不出现**「第N章 / 上一章 / 下一章 / 前N章」 |
| 设定 | `world_spec.power_system.tiers` 非框架术语；`volume_world_disclosure` 至少一卷非空；伏笔非方法论 |
| 逻辑 | 概念矛盾判据留下回执（有无矛盾都要留） |

**不算数的**：某一本书碰巧干净。只有**回执链**（检出→重写→采纳→干净）和
**跨书重复**才算证据。
