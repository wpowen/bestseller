# 章节生成模式 A/B Test

## 目标

比较两条真实生产路径在同一章节合同下的正文质量：

- `scene_by_scene`：分别生成 3 个场景，再按因果顺序合并为章节。
- `chapter_first`：在一次模型调用中直接生成完整章节。

首轮只比较模式，不在运行过程中修改提示词。

## 控制变量

- 写手模型固定为同一个模型与同一 writer 角色参数。
- 每对样本共享题材、人物、前情、章节目标、必须事件、禁用套路和目标字数。
- 三个测试章节覆盖开篇压力、关系冲突、公开兑现三种功能；题材为现实经营故事，不以悬疑作为默认样本。
- 两种模式都只能输出连续正文，不允许显示场景标题或策划标签。
- `scene_by_scene` 的后续场景只额外得到前一场结尾，防止无上下文拼接；不提供未来正文。

## 评估

### 确定性检查

- AI 味检测分及高置信模式分类。
- 必须事件覆盖率与事件顺序。
- 字数、可见场景标题、策划标签泄漏。
- 段落与短独行段统计仅作诊断，不直接决定胜负。

### 双模型配对盲评

- 判官不知道生成模式，只看到“文本 A / 文本 B”。
- 每个判官对同一对正文做两次位置互换评审。
- 四个主维度：AI 味低、逻辑严谨、故事性、可读性，均为 0-10 分。
- 总分权重：AI 味 30%、逻辑 30%、故事性 20%、可读性 20%。
- 每项必须引用正文证据，禁止仅凭文风印象打分。

## 终止与决策条件

- 固定完成 3 组配对样本、2 个跨家族判官、每对 2 次位置互换，共 12 次盲评。
- 任一生成调用使用 fallback、正文缺失或严重越界，则该样本无效并停止结论。
- 位置互换一致率低于 75%，结论为 `inconclusive`。
- 候选模式须在至少 2/3 组样本胜出，且加权均分领先至少 0.30/10。
- 胜者的必须事件覆盖率不得比另一组低 0.05 以上。
- 未满足全部条件时明确输出“首轮无明确赢家”，进入下一轮扩样，不强推上线。

## 首轮边界

三组样本足以发现明显模式差异，但不足以证明所有题材都同样成立。若出现明确赢家，下一轮再扩到玄幻、都市情感和非悬疑职场各 3 章做回归。
