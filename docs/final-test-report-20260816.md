## 五、修复端天花板：DITTO 前置拆链（2026-08-16 补）

**问题**：整章重写治不好重症章，卡在 6/17。加轮数无效（rounds=4 与 2 无差异），
改指令只把残留减半。

**根因**：DITTO 自我强化（NeurIPS 2022, arxiv 2206.02369）——上下文里某句
重复越多，模型继续重复它的概率越高。每一轮模型都在照抄眼前满屏的病文。

**解法**：不是让它改得更用力，而是**交稿前把模板机械拆掉，让它看不见**。

- `collapse_moment_slice_chains()`：确定性拆除顶针接力链
- **顶针守卫是关键**：切片前缀的词必须在前 40 字内刚出现过才拆。孤立的
  「门倒下的那一瞬间，他看清了里面的人」前文没有「门倒下」，不拆——
  没这道守卫，机械拆解会把事件本身删掉。窗口放宽到 80/120 实测无收益。
- 触发用**基础档**（1.2）不是病态档（3.0）：拆链对干净文是 no-op、孤立用法有
  守卫，代价为零；挂病态档时 ch31/ch50 一次都没拆过，白留着链给模型抄。
- 拆完有语法接缝，prompt 加定向提示让模型顺句，并明说别把承接方式加回来。

**效果**（真机 E2E，17 病章 + 3 健康对照）：

| | 拆链前 | 拆链后 |
|---|---|---|
| 密度均值 | -53% | **-77%**（4.32→0.99/千字） |
| 病态档章数 | 12 → 6 | **12 → 0** |
| 最高值 | 6.86 | **2.43**（原 11.98） |
| 治愈（严格线 <1.2） | 6/17 | 11~13/17（跑间方差） |
| 字数守约 / 健康章 | 15/17 / 3/3 | **17/17 / 3/3** |

单章例：ch25 11.98→0.45、ch24 7.33→0.70、ch8 6.83→0.00、ch26 5.35→0.00。

残留 4-6 章落在 1.25~2.43，**全部跌出病态档**，逼近人类全语料最大值 1.14。
跑间方差存在（11/12/13 各出现过），单次数字不宜过度解读。

## 七、运维教训

- **`pkill` 硬杀 Docker Desktop 会让全栈容器消失**（数据卷完好，
  `docker compose up -d` 可完整恢复）。改用 `osascript quit` 并耐心等待。
- **跑书期间不要重启容器**：worker 被杀 → 自愈把孤儿 run 收尸 → 书死在
  planning。本轮因此损失一次构思。
- `data/` 此前不是活挂载，改检测器规则需 rebuild；已在 compose override 补上。
