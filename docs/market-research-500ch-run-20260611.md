## Objective

## Market Direction

Chosen direction: **urban cultivation 2.0 + occupational bureaucracy + reality-pressure progression**.

Rationale:

- Current Chinese web fiction signals favor strong hooks, rapid retention loops, and clearly legible reader payoffs over abstract genre labels.
- The best local fit is not traditional xianxia, but a modernized cultivation wrapper: public systems, jobs, exams, urban incidents, institutional pressure, visible promotion rewards, and rule-exploitation reversals.
- This direction matches the repository's existing `urban-cultivation-2.0` prompt pack and avoids forcing female-audience identity melodrama into a framework currently stronger at male-frequency upgrade loops.

- `https://www.cssn.cn/skgz/bwyc/202604/t20260420_5981165.shtml` - the 2025 China web literature report emphasizes diverse creator occupations, reality-grounded experience, traditional-culture deepening, expanding type lanes, and upgraded narrative mechanisms.

## Tracking Method

Authoritative sources for this run:

- `projects`: creation/status/current chapter.
- `workflow_runs`: workflow type, status, current step, error message, metadata, created/updated timestamps.
- `workflow_step_runs`: step names and step statuses.
- `llm_runs`: model, logical role, prompt template/hash, latency, tokens, created time.
- Redis `arq:*`: active queue/in-progress evidence.
- `output/civil-service-cultivation-market-1781109344/`: exported project and chapter files.
- Real chapter text and quality reports before declaring chapter 1-10 accepted.

Known timing limitation:

`workflow_step_runs` has `created_at` but no `updated_at`, so per-step elapsed time cannot be read directly from that table. Stage timing will be triangulated from workflow row timestamps, LLM latency totals, worker logs, CLI progress output, and artifact modification times.
