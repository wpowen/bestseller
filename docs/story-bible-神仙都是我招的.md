# 《神仙都是我招的》故事圣经

> 一份纲领性文档：读完它，你能掌握这个故事的全部核心设定、逻辑链与人物关系，并据此构建整部小说。
> 定位：都市脑洞 · 游戏现实主义 × 神明招募 × 职场喜剧 · 番茄男频（轻喜+暖+悬疑）· 目标 500 章
> 立意一句话：**所谓封神，不过是人性的试用期。**

## 一、电梯陈述

**一句话**：失业 HR 入职一家薪资高得离谱的诡异公司，按奇葩 JD 招人，后来发现公司是天庭、他招的全是神仙——而他不知道的是，这场招聘真正的考核对象只有他一个：天帝候补·第七人。

**三句话**：
1. 天庭缺编一千年，老神到龄退休，神职移交需要"人岗匹配"——这恰恰是凡人 HR 的专业、神明的盲区。
2. 主角陈屿没有任何神通，他的神通是**通讯录**：他招进来的每一个神，都接他电话。
3. 他业绩越好，职级越往下掉——因为天帝位无品阶，系统正在悄悄剥离他的编制；而他招的每一个人，最后都成了他渡劫的答案。

## 二、平台简介（点击钩子）

> 灵气枯竭千年，诸神终于撑不住了。
>
> 他们决定退休，把神职移交给人间——可凡人不信神，硬塞会反噬。于是天庭在人间注册了家公司，对外招聘"继任者"。
>
> 失业三个月、被前公司背调使绊的 HR 陈屿，入职了这家月薪八万的"三垣人力资源有限公司"。第一份 JD 就让他想报警："江底水文管理员，会游泳者优先""月面夜班值守，需自带交通工具"，薪资栏写的不是钱，是"香火"。
>
> 直到他亲眼看着一个外卖小哥在他手里签字封神，金光冲天。
>
> 工牌背面有一行小字：**"第七任。祝你比前六位幸运。"**
>
> 他翻开公司人事档案——前六任 HR，离职原因，全部空白。

**三层钩子**：①月薪八万的诡异公司招的是神（撑前期单元剧）→②前六任 HR 全部出局，他是第七任（撑中期悬疑）→③真正被考核的是他、天帝位的终极悖论（撑后期主线）。

## 三、世界观基石：信力经济学（亮点·一条公理推出整个世界）

> 这是全书逻辑最硬的部分。所有设定都是这条公理的**推论**，不是补丁——这让世界观经得起任何推敲。

### 公理 0：神力的本质是信力

**神不产生力量，神是信力的转化器：**

```
人间信仰 → 神力 → 履职（治水/断案/守护/镇压）→ 人间安定 → 更多信仰
（信力大循环，总调度 = 天帝）
```

### 公理 0.1：信力渠道律

信力必须经 **名号 / 岗位 / 形象** 三类锚点之一才能结算，无锚的善念不计入。
（这一条同时解释了三件看似矛盾的事：守岗土地公被居民记两百年却仍会耗尽——记的是"土地庙"岗位锚，只够维持职能不够续命本体；灶王爷全民皆知却枯竭——祭灶记忆锚在"习俗"非"名号"，折损率极高；二郎神红遍全网却养不起一条狗——见下文 IP 层。）

### 由公理推出的全部世界规则

| 推论 | 内容 |
|---|---|
| **神的寿命 = 信力余额** | 神不是天生不死，是"在编不老"。断供即折旧：先失神通 → 再失神形 → 最后失神识。"老神到龄退休"的真相是**余额见底**，趁耗尽前体面离场。 |
| **岗位必须有人** | 神职是世界的运维岗。空转的恶果分级：土地缺编→地气紊乱（灰雾，人心冷漠的具象化）；城隍缺编→阴阳司法真空→厉鬼滞留；龙王缺编→水文失序；**武职缺编→封印松动→妖魔出栏**。 |
| **流量即香火** | 现代注意力经济在截流香火——人类念力总量恒定，全流进了手机、职场、焦虑。这是"流量即香火"的残酷反面。 |

### 失序事件链（为什么是现在开书）

1. 千年前，天帝被天道稽核程序"**司衡**"按他自己写的章程清退——信力大循环失去总调度。
2. 司衡代行，按降本逻辑断供"低产出"神职 → 恶性循环（断供→失灵→更没人信→再断供）。
3. 现代化加速：注意力经济把香火截流进平台数据资产。
4. 武职最吃信力（战斗=大功率输出），**崩得最快** → 镇压网千疮百孔 → 妖魔/灵异抬头 → 故事从此刻开始的时代必然性。

### 显圣税与"去锚"（亮点·法力为什么不能随便用）

降噪协议的精算版——**司衡为降低维护成本，千年来把超凡事件从凡人认知里对账抹平**（事故化、自然化、都市传说化）：

- 在凡人面前动法力，抹平目击者记忆的算力费由**施法者预缴**（烧自己寿命）+ 司衡执行带宽决定抹平质量。**显圣一次=烧一次养老金**，大能们在人间克勤克俭。
- 余额不足者动法力触发"**去锚**"：暂时从凡人感知中消失（社会性死亡——账号登不上、房东看不见你、外卖没人接）。
- 在编者有**公务显圣额度**，月底清零。
- **近年清算挤占算力，降噪开始穿帮**——灵异频频上热搜，这是司衡虚弱的信号，也是故事的引爆点。

### 神的退场三路径（亮点·转世制度）

| 路径 | 机制与代价 | 剧情功能 |
|---|---|---|
| **转世** | 神识入轮回换一世凡人寿命，可选**留忆/洗忆**——留忆者承受"凡身载神忆"之苦（记得自己曾移山填海，如今搬不动一桶水），多数选洗忆 | **地府不是对手，是天庭的离职安置服务商**；转世潮挤爆轮回司=女主孟拂家也缺编的原因 |
| **化形** | 降格转灵兽编（低功耗待机）——**灵兽多是旧神** | 躺平线的逻辑根基；新聘凡人也可入灵兽编（周大力躺平案） |
| **守岗** | 拒退拒转，硬撑到神识耗尽**无声消散**，连转世机会都耗没 | 老街土地公守了两百年的真相；每卷单元剧的催泪引擎 |

### 四层存续：谁会消散、谁不会（亮点·天庭不是空的）

**消散的判定 = 被遗忘。**

| 层 | 机制 | 代表 |
|---|---|---|
| **自有信力层（不灭）** | 力量自修或本身即"道"，不靠香火 | 孙悟空（五百年压山自修的真元）、太上老君（无为即道，越不做道越完整） |
| **IP 长青层（半灭）** | **二创即香火**：影视/动漫的持续记忆是新香火，但有杂质——**神会被观众认知反向改写（人设漂移）** | 猪八戒（被喜剧化到正经本事被锁死）、二郎神、哪吒 |
| **职能在编层（凭岗续命）** | 岗位职责产生职务信力，干一天有一天 | 城隍/土地/灶神——缺编重灾区，招聘主战场 |
| **消散层** | 无自有力、被遗忘、无岗位 | 无名小神——单元剧泪点 |

### 威胁供给系统（亮点·妖魔从哪来 + 500章烧不完）

- **封印不是法术，是岗位**。武职缺编→封印松动→妖魔出栏。**威胁强度 = 岗位空缺时长**，这是天然的 500 章升级曲线：灵异事件（卷1-3）→妖魔出栏+**堕神**（卷4-7）→体系级总清算（卷8-10）。
- **堕神 = 被司衡断供逼疯的旧神堕落成魔**（被裁员逼疯的前员工）。**司衡的降本制造了它要清算的混乱——算法自噬**。反派从此不靠名单，靠系统生成。

### 体系级闭环（亮点·算法自噬第二例）

司衡的降噪协议把神迹改写成"营销号段子"——而段子传播产生的二创香火，**恰恰养活了它要清算的神**。司衡在不知不觉中给神续命，这解释了它千年清算不净的原因。网络梗是神存在的合法泄洪口。

## 四、金手指：天命人事档案（亮点·四件套，独此一家）

| 组件 | 能力 | 约束（防崩坏） |
|---|---|---|
| **识人面板** | 看穿任何人的命格履历、隐藏技能、神职适配度——扫地僧式素人一目了然 | **看不见自己的面板**（无命格者）；面板只给适配度不给答案，且会被旧伤干扰误读（卷一就让它认过错） |
| **Offer 即封神** | 签发的录用通知具封神契约效力，签字即授职 | **必须对方自愿签字才生效——不能替人做主**；权限逐卷升级：授职→调岗→开除恶神→创设新职位 |
| **离职赠礼（信物体系）** | 每位他体面送走的神，把一缕残余信力寄存在信物里赠他（土地公方寸符/城隍观罪一瞥/灶神半块灶糖/龙王一鳞/嫦娥清辉/杨戬天眼借光） | 每件**一日一用、单次低功率**——他不变成战士，但不再是纯凡人。本质是"通讯录即神通"的实体化 |
| **功德账本** | 司衡记他"扣分"，天道记他"功德"（同一行为两套账，主题对仗） | 面板随功德进化：看人→看岗→**看信力流向**（卷8解锁=天帝视角入门）。终局改章程的资本=十卷攒下的功德 |

**核心定位**：陈屿是**姜子牙模型——调度者不是战士**。每次对抗的爽点 = 识人面板+通讯录调出"正确的人打正确的怪"（水鬼案调龙王候补、大妖出栏给杨戬配齐轮班）。**知人善任就是他的战斗系统**（军师流/帝王流爽感）。

**为什么"无命格者"是被选条件**（亮点·反算法游击战）：司衡能读取并预测一切有命格者（六代泄名单就是这么精准投放的），唯独算不到无命格者。候补制 = 天道在算法眼皮底下打的反算法游击战。

## 五、主角陈屿（人物核）

- **身份**：27 岁失业 HR，前大厂 HRBP，因拒写"恶意优化"名单被反向优化——**因善被裁**，这正是天道选他的隐藏原因。
- **want / need / 张力**：want=把这份钱多的工作干稳、挣回体面；need=重新相信"把人放对位置"本身有意义；张力=他越用心给别人找位置，越被推向他最不想要的那个位置。
- **压抑层创伤（人物的魂）**：当年那份 37 人优化名单他拒绝写——可换了个人照样写了，37 人照样没了。**他的善良失败过**，所以后来每次"把人放对位置"都是在还债。死穴=那份 37 人名单（卷9姜暮拿它诛心："你的原则救过谁？"）。
- **性格识别符**：口头禅 **"人没有废的，只有放错的。"**；压力下把东西摆成直角；**越生气越客气**（敬语逐级升格，"您"一出口就是动真格）；用职场黑话形容一切（"这场雨还在试用期"）；不说谎只说半句（"工资是真的"——没说雇主是谁）。
- **绝对原则**：只递 offer，从不逼签字——绝不替人决定人生。（与"尊重躺平"主题焊死。）
- **动机演进**：为钱（生存）→为人（招进来的每个都是责任）→为众生找位置（候补自觉）→**拒绝位置本身**。

## 六、双暗线（亮点·全书悬念脊柱）

### 暗线 A：第七任候补

这场招聘真正的考核对象是陈屿——天帝候补·第七人。**前六任 HR 全部以同样身份入职过，全部出局**：两位入编后被职位异化、一位疯、一位失踪、一位自请除名、第六位黑化成反派。他业绩越好职级越降，因为**天帝位无品阶，候补不能持有任何编制，一旦入编即丧失资格**——系统在自动剥离他的职级。情感落点：全天庭最后发现，**唯一没有编制的人，托着所有人的编制**。

### 暗线 B：候补不止一人

天道的禅让考核从来是**多候补并行**——每代在天庭/地府/灵山/道盟各序列散布候补，彼此不知情。考核真正测的是：**知道有竞争者之后，你还能不能公平地"为众生找位置"——包括为你的竞争者**。

- 本代候补：陈屿（天庭·第七人）、**孟拂**（地府·轮回司HR，女主，自己不知情）、**无名**（灵山·扫地小沙弥）、道盟序列空缺（因"第零人"玄一千年前拒绝后再无人入选）。
- **前六代败因深层真相**：不是能力不够，是知道"还有别人"之后的反应——内卷崩溃、抢跑夺位、互相出卖，第六代姜暮直接对同代候补下了手。而幕后：**司衡每代都泄露候补名单、安排"偶遇"、制造稀缺感**，要证明禅让制必然失败，从而合理化无神模式清算。前六代的尸骨全是它的论据。
- **陈屿的破题（卷9高光）**：拿到名单后他做的第一件事是把名单摊开，找孟拂、无名组队——"考卷上不是只有我一个名字？那就组队答题。"千年来候补第一次不是相残是互补。这是天道等了一千年的答案。

## 十、神职转职升华 + 核心理念

### 转职三级递进（亮点·神性内化为人性）

不是"灶神→食安督导"的岗位平移，而是：
1. **续聘**（前期）：给旧岗位招继任者——解燃眉之急。
2. **转型**（中期）：把岗位接到现代信力管道上——少量保留作喜剧。
3. **升华/撤编**（终极）：当一种神职守护的人间价值**已内化为普遍人性**，岗位功德圆满，可以撤编——灶神守的是人间烟火，当"好好吃饭、家人围桌"成为人人珍视并互相守护的事，灶神就不需要了。**神职的终点不是有人接班，而是不再需要接班。**

主角的终极工作由此改写：分辨三类岗位——必须有人的（武职镇守）、可以转型的、**应该还给人间的**。人事部终极 KPI = 把神性还给人性。

### 与司衡的终极辩证（亮点·高级反派的最高形态）

司衡说"无神模式成本最低"。陈屿的反驳不是"必须有神"，而是："**你说得对，但路走反了——无神模式的前提不是清算神，是养成人。砍脚手架之前，得先让楼自己能站住。**"司衡要裁员式无神，主角给毕业式无神。反派方向对、方法错。

### 核心理念

- **哲学命题**：神明本是人心的代班者。上古人心未满，诸神代班；今人心已成，当还位于人。
- **金句**（全书反复回响、可印在简介里）：**"所谓封神，不过是人性的试用期。"**——封神/试用期双关，与书名、主角永远转不了正的职级线、转正结局四向咬合。最终章落点：**试用期满，转正的不是某个神，是人间。**
- **母题**：主母题"代班与交还"；子题：平凡的正当性（躺平的正当）、记忆与遗忘（消散=被遗忘、孟拂怕忘、留忆转世之苦）、被观看与被定义（八戒的人设牢笼）。
- **现代制度明线**：21世纪不容皇权科层制。改革阶梯：卷4嫦娥排班制→卷5转岗计划→卷7返聘制→卷8全民补编→卷10空位制+轮值理事会+任期制。**终身制权力必然异化（初代天帝→司衡），解法不是换个好人，是改成不依赖好人的制度。**
