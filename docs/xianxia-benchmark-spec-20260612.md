# 修仙长篇基准试跑规格（2026-06-12）

> 目的：用一部**原创**修仙史诗压力测试框架的"正文前准备包"产出能力。
> 《凡人修仙传》只作为**结构规模参考**（境界数/势力数/伏笔跨度/卷数量级），
> 不复制其剧情、人物、宗门、地名、台词、文本表达或可识别创意组合。
> 质量判定一律使用下方"可检查结构指标"，不使用"像某本书"作为证明。

## 一、结构复杂度对标（仅取量级，不取内容）

| 维度 | 对标量级 | 本基准目标 |
|---|---|---|
| 篇幅 | 千章级长篇 | 10 卷 / 500 章 / ~110 万字（规划层全量，章纲取样例批次） |
| 修炼体系 | 多大境界×多小阶，硬瓶颈 | ≥7 大境界，每境界分阶，境间有"天槛"硬瓶颈 |
| 势力 | 宗门/王朝/魔道/异族多方 | ≥5 个独立势力，跨卷有兴衰与格局重组 |
| 伏笔跨度 | 跨数百章回收 | ≥10 条登记伏笔，≥3 条跨度 ≥3 卷 |
| 主角形态 | 凡人流：平庸资质+隐秘外挂+谨慎性格 | 同形态，但机制/代价/身份全部原创 |
| 界域 | 多层世界递进 | 3 层界域（浊土→澄洲→上垣） |

## 二、原创基准设定《蚀漏砚》（premise 全文）

主角谢迟，十七岁，北境盐泽镇称量行学徒，生而"浊脉"——灵力浑浊，引气入体便是天花板，被三家道统的外门考核接连黜落。盐泽镇遭夜火灭镇当晚，他从塌陷的义仓地窖里挖出一方缺角古砚"蚀漏砚"：研墨滴血，砚池方寸之内光阴加速百倍，灵草一夜千日、丹毒朝种暮解、功法推演如十年苦修；但每用一次，砚底便浮出一行小字，记走他一段寿数。修仙者求长生，他的外挂却以寿数计价——练得越快，离长生越远。谢迟靠砚台伪装成"丹草奇才"考入衡山院外门，一面在宗门倾轧中谨慎求活，一面追查灭镇真相。修炼体系七境：引气、通脉、凝府、丹枢、洗象、照神、问衡，境境之间隔着需机缘与道悟方能跨过的"天槛"，而"问衡"之境已三千年无人在世。世界三层：凡俗诸国所在的浊土、宗门林立的澄洲、只存于残卷的上垣。五方势力角力：把持灵材流通的凡俗商盟"盐铁会"；三大道统——官修背景、奉平衡之道的"衡山院"，贩卖情报与杀契的"雾外楼"，垄断丹草的"栖梧宗"；被正道斥为左道的上古祭祀残部"巫祠遗脉"；以及域外散修结成的"荒泽蛮修"。百年一度的灵潮即将复涨，资源格局重洗在即。长线悬念：蚀漏砚是上垣陨修遗物，砚中residual残识偶尔代笔写字；被记走的寿数没有消失，而是在砚底"养"着什么；灭镇夜火与衡山院内部有牵连；灵潮的枯涨周期背后存在人为闸门。主角动机链：活下去→查清灭镇→在体系内站稳→直面"以寿换力"的悖论→走通无人走通的问衡之路，以衡换生。关键配角：同乡幸存者孤女宋拾（后入雾外楼）、衡山院落魄执事关铎（知晓内鬼线索）、栖梧宗药圃监工裴萤（发现谢迟丹草异常的第一人）、巫祠遗脉少祭白杪。

### 原创性自检
- 金手指：砚台+方寸光阴加速+寿数计价+砚中残识——与"小瓶催熟灵液"机制、载体、代价、来历均不同；"时间加速"为题材公共惯例，代价设计（寿数账本）为本设定独有。
- 人名/地名/宗门/境界名：全部新造（谢迟/盐泽镇/衡山院/引气~问衡），与原作无一重合。
- 剧情：灭镇悬案+商盟/道统/遗脉三角+灵潮闸门，均非原作情节。

## 三、可检查结构指标（验收标准，替代"像凡人"）

| # | 维度 | 达标线 | 检查方式 |
|---|---|---|---|
| S1 | 升级体系一致性 | world_spec.power_system 境界 ≥7 且有序；卷纲/章纲中主角境界引用单调不回退；每卷大突破 ≤1 次 | 解析 artifact JSON 程序化核对 |
| S2 | 势力演化 | ≥5 势力入册；十卷中势力状态变化（结盟/敌对/兴衰）≥2 次格局重组且分布在不同卷 | 卷纲逐卷核对 faction 相关字段 |
| S3 | 伏笔回收 | 卷纲 foreshadowing_planted/paid_off 登记 ≥10 条；≥3 条 plant→payoff 跨度 ≥3 卷；无"植了永不收"的孤儿伏笔（10 卷内全闭环或显式留续作） | 全卷纲伏笔台账核对 |
| S4 | 角色动机 | 主角每卷卷目标可追溯上卷结果；关键配角 ≥4 人有独立动机与弧线字段非空 | 卷纲+cast_spec 核对 |
| S5 | 卷级节奏 | 10 卷 arc 形态无连续 3 卷同构（对齐登记册 R8）；reader_hook_to_next 十卷互不相同且非模板句（对齐 R9） | 卷纲逐卷比对 |
| S6 | 章级可写性 | 章纲样例批次中 opening_situation/main_conflict/target_emotion/hook_type/causal_contract/场景 participants≥2 填充率 100%（对齐 R6） | 章纲批次程序化核对 |
| S7 | 正文前置条件完整性 | 写手上下文包 dry-run 含：世界规则/修炼体系(progression)/势力状态/伏笔(clue)注入块、场景卡 entry/exit 链式衔接 | 渲染代表章 prompt 检查块清单 |
| S8 | 长篇连贯性 | 章纲批次间无同事件弧线重复规划（对齐 R5 台账）；物化后 narrative graph 中 clue/payoff 数 >0 | 跨批次事件比对 + DB 核对 |

## 四、试跑参数
