# 《神仙都是我招的》re-seed premise — 天庭名角招募爽文喜剧

> 用途:作为 zhaoshen-hr 重规划的 premise 种子。核心维度 = 让人看了心情愉悦的**爽文喜剧**;脑洞/喜剧/爽点必须**贯穿全书**,不是开篇噱头。

## 一句话卖点
失业HR陈屿成了天庭千年老国企"神职人力资源部"唯一的HR——这里冗员错配、名角躺平、裸辞成风,而他每把一个被放错位置的神仙**放对位置**,人间的现实就被改写一层。

## 主角
- 陈屿,27,人间大厂被反向优化的HRBP。信念:**"神没有废的,只有放错的。"**
- 心结:曾因拒写恶意裁员名单背了 37 人的黑锅(死穴)。
- 金手指:**招对/调对一个神 → 人间现实改写一层**(他的处境、母亲的病、老街香火)。
- 隐藏主线(不变):他是天帝第七候补,KPI 越高越接近那个位置;天庭考核的从来不是业绩,是他这个人 → 业绩越好离位置越"远"的反转。

## 贯穿引擎(每 3-5 章一个名角 set-piece — 保证喜剧脑洞不断档)
1. **招** — 一个放错位置的天庭名角带着"职场痛点"登场(脑洞喜剧 set-piece:裸辞/摆烂/被优化/内卷)
2. **看穿** — 陈屿用 HR 本事一眼看穿他不是废,是被错配(爽点:看穿)
3. **安置** — 重新设计岗位/调岗,名角"上岸"(爽点:逆袭+扬眉)
4. **兑现** — 安置解决一个当下危机 → 人间现实改写一层(爽点落袋+代价钩子)
5. **建队** — 名角入队,姜子牙式攒团队,为后续更大危机蓄力

## 第一卷名角 roster(招募/出场顺序)
1. **哮天犬**(ch1 离职开篇)— 顶级缉妖天犬被二郎神派去看天门,大材小用,叼着辞职信裸辞。安置=老街缉妖巡夜首席。忠犬×暴躁打工人反差。**开篇大脑洞:神仙也要找HR跳槽。**
2. **老土地公** — 退休返聘、佛系躺平的老土地,KPI 考核不及格面临"优化"(神仙版 35 岁中年危机)。安置=社区运营/在地情报。
3. **千里眼 · 顺风耳** — 天庭监控中心被边缘化的外包二人组,全知却没人听;陈屿调成"市场情报部",反碾压灵山(爽点:情报降维打击)。
4. **雷震子** — 暴力输出却被困文职。陈屿先错位让他做催收/客服(错位喜剧)再归位成"危机处置"。

## 反派线(服务于喜剧爽点,不喧宾夺主)
- **灵山集团** — 把天庭"信力"私有化收购的资本方;用合规/流程/KPI 这套现代职场话术压人(职场 PUA 的神仙版)。
- 代表:应潮生(体面型合规压制)、周敏(录音/把柄)、韩郅(资本顶层)。
- 每卷一个"收购/截胡"危机,被陈屿带着名角团队用"把人放对位置"的方式反杀。

## 基调硬约束
- 喜剧 45% + 爽点/逆袭 30% + 暖 15% + 悬念 10%。
- 喜剧来自**身份错位 + 神仙过现代职场**(编制/KPI/调休/背调/Offer/35岁危机),不靠低俗或meta吐槽。
- 每章必须**推动剧情或改变关系/压力**,喜剧不空转。
- 名角保持人设不崩(persona-safe):哮天犬还是那条忠勇暴躁的神犬,只是换了语境。
