# 「一句话创意」提示词工程分析（2026-08-24）

对象：`concept_tournament._build_raw_idea_pool_messages`（prompt_arm=author_pitch，生产默认）
及其配套判官 `_build_raw_idea_rank_messages`。
方法：外部模型指控逐条核验（对照仓库内消融数据 + 生产 DB 真机产出），再做独立的
提示词工程审计。

## 〇、结论先行

外部模型三条指控：**一条成立、一条症状对、根因错，一条观察对、修法会复辟已证死的病**。
但它没看到的三个结构性问题更重要：**判据双载、单句槽位超载、幸存者模式当生成铁律**。
这三条在我们自己的生产数据里有实证，不依赖外部模型的生成样本。

---

## 一、外部指控逐条核验

### 指控1：铁律四（事件先行+当场兑现）× 铁律二（主角主动）冲突 —— ✅ 成立

两条同时可满足的区域确实存在（主角自己动手做的事已发生并当场兑现），但 prompt
没有把这个交集写出来，而是各自独立陈述。模型在单句预算下最省力的解法是：
**外部事件砸到主角头上（满足四）+ 补一句主角"偏要"（表面满足二）**。

生产实证（不是外部模型的样本，是我们自己 M3 走完整漏斗后的**冠军**）：
- 《废丹成神》：开局是「新律逼我当众吞丹」（被动应激），然后用约 400 字逐条枚举
  "为什么所有退路都是死路"来论证主角"主动留下"——典型的表面合规。
- 《别人借力我替他们还债》：logline 原文「他只想烧账本躺平，账本偏把他拽进风暴
  中心」——**直接违反铁律二仍然加冕**。铁律在生成端根本没有拦住它，判官端的
  被动 cap（≤4）也没拦住。

判定：冲突真实存在，且两端（生成铁律+判官 cap）都对它失效过。

### 指控2：铁律五（因果可懂）× 铁律六（嫁接新鲜）冲突 —— ⚠️ 症状对，根因错

外部模型举的例（算命→天雷劈死长老=概念偷换）其实是**违反**铁律五，不是铁律五
和六打架造成的。真正的根因是下面第三节的「单句槽位超载」：一句话同时要装
欲望+主动+已发生事件+当场后果+机制因果+嫁接结构+人话动词，模型的压缩策略
就是**把"后果"和"机制演示"合并成一格**——于是"当场兑现"被写成"当场跨境界"，
读起来就是战力膨胀无铺垫。症状诊断正确，病灶定位错误。

### 指控3：一次 12 条+绝不重样=认知过载，应分批 —— ⚠️ 观察部分对，修法必错

**分批是本仓库用单变量消融明确证死的方案**（config/concept_tournament.yaml 注释，
2026-08-10，东方玄幻/男频，每格 40-48 样本）：

| 采样结构 | 同族塌缩率（死亡/丧葬族） |
|---|---|
| 每次 1 条 | **60.4%** |
| 每次 1 条 + focus | 41.7% |
| 一次 8 条 | 20.0% |
| 一次 12 条 | **7.5%** |

多样性是集合层面的属性，一次只生成一条就没有集合可言。改回分批=同质化复辟 8 倍。
外部模型没有这份数据，按通用直觉给药，药方与我们的实测正好相反。

尾部质量退化（第 7-12 条被排重规则挤压）的观察**可能**为真，但：
① 池子有 3 倍超采+判官只取前 8+7.0 分门槛，尾部废品本来就设计为被剪掉；
② llm_runs 没存 response 正文，**尾部退化目前无法用存量数据证实**——要下结论
需先做按 index 分组的质量量测。在量测之前不动 batch 结构（"停止做某事≠这东西
坏了"的教训同款：别凭外部样本给已消融验证的机制定罪）。

低成本缓解（不动 batch）：把「必须 12 条」改成「宁缺毋滥——想不出第 12 个不重样
的就返回 10 个」。**补齐兜底（topup_calls=2）本来就存在**，允许短产的成本已经
被架构消化了，现在却在 prompt 里逼模型硬凑满额。

## 二、独立审计的三个结构性问题（比外部指控更重要）

### 问题A：判据双载——生成端和判官端背着同一本规则书

逐条对照，生成 prompt 的铁律与排序判官的 cap 几乎一一同构：

| 生成端铁律 | 判官端同款 |
|---|---|
| 铁律一 欲望钩 | click_seed「说不出想看赢什么 ≤4」 |
| 铁律二 主角主动 | 「全程被动 ≤4」 |
| 铁律三 不写机制句 | 「对称机制条款 ≤4」 |
| 铁律五/六 机制+嫁接 | freshness「无框架可挂载 ≤4」 |

量化：生成 user prompt 1327 字里「作废」×7、「必须」×8；判官 1802 字里
「不得超过」×12。**同一规则书写两遍，换来的不是双保险，是生成端的防御性写作**：
《废丹成神》的 logline 就是实证——它不是在讲故事，是在**逐条向 character_logic
和 promise_survival 轴答辩**（枚举六条退路为什么都走不通）。产物长成了判据的形状。

这与已定案的判官教训同构（hook-pull-judge-first-validation：缺陷清单塞进评分
调用=注意力稀释）。当时的根治是拆双通道；生成端的对应根治是：**生成 prompt 只
carry「好的样子」+少数硬约束，规则书留给判官**。反正废品会死在漏斗里——这正是
漏斗存在的意义。

### 问题B：单句槽位超载——义务全压在 seed 字段，辅助字段闲着

七条铁律里有五条明写「这一句话里必须…」。数一下 seed 单句要同时承载的语义槽：
欲望钩、主角主动、已发生事件、当场后果、机制因果、嫁接结构、人话动词——**7 个
槽位挤 40-80 字**。而输出契约里明明有 opening / why_it_keeps_moving /
future_situations 三个辅助字段，却只被定义为「帮你想通，不进下游」，不承接任何
铁律义务。

修法：显式分配义务到字段。seed 只保欲望+事件+后果三槽；机制因果落 graft/opening
（「嫁接后机制在新场景为什么仍成立」一句）；持续性落 why_it_keeps_moving。
注意：排序判官此前**只看得到 lane+seed**（rows 构造只送这两项），义务搬进 graft 就必须同步把 graft 送进判官，否则判官仍在给刚被搬走义务的那个字段打分——已随本次重构一并接线（pitch_by_seed→rank rows）。

### 问题C：幸存者模式被写成了生成铁律（制度化拼凑）

铁律六源自榜单 70 本蒸馏「57% 头部=熟机制×意外场景」。但 57% 是**冠军分布**，
不是**生成规则**——把它写成 12/12 每条「必须是一次嫁接、否则作废」，等于把
剩下 43% 的成立方式全部非法化，并把「拼凑」制度化为新鲜的唯一定义。用户抱怨的
「生硬拼凑」有一半是这条铁律**按设计**产出的。

修法二选一：① 降为默认策略+逃生门（至少 2/3 用嫁接，其余允许其他成立方式）；
② 保留铁律但补上缺失的因果桥义务：graft 字段必须多写一句「这个机制搬进新场景后
靠什么仍然成立」——现在的 graft 只要求写「A×B」，恰好缺的就是断层处的那根梁。

## 三、次级问题（顺手修）

1. **12 条 vs 8 种欲望形态的算术张力**：多样性令列了 8 种具名欲望形态+「……」，
   却要求 12 条各不相同——后 4 条被迫生造或违规。改成「至多重复两次」或扩菜单。
2. **死重**：悬疑例外、灵异异常来源段在纯玄幻调用里照样渲染（约 180 字纯噪声）。
   代码有 genre 信息，按题材条件渲染即可。
3. **调性三重冗余**：`调性：热血…`（system 指令）+ `"tone":"hot"`（JSON）+
   「用人话说…高热快节奏」（picks 行）说了三遍。留人话版+JSON 存证即可。
4. **铁律编号乱序**（七在六前）：accretion 的痕迹，顺手排正。

## 四、这条 prompt 修不了的病（别错怪它）

近 5 本书里 3 本带账本/债务隐喻（「过账/审计司」「账本/债主」「还债/账本」）。
这不是本 prompt 的规则冲突——批内多样性令只保证**一批之内**不同，每本书都从同一
个模型先验里独立抽样，跨书塌缩照旧（已定案：motif-amplification-profile-layer，
过滤点在母题出生之前；治它的层是跨书私货清剿/概念级去重，不是这条 prompt）。

## 五、动与不动清单

**不动**（有消融/探针证据背书）：batch=12 整池生成、场域多样性令、频道锚挂
system、seed 只当罗盘的措辞（四臂对照定案）。

**动**（按收益排序）：
1. 生成端瘦身：铁律降为「好的样子」+3 条硬约束，规则书留判官（问题A）
2. 铁律二+四合并成一条正向复合句：「主角自己动手做的一件事已经发生并当场兑现
   后果」（指控1）
3. 义务分配到字段，seed 只保三槽（问题B）
4. graft 补因果桥义务 或 嫁接降为默认策略（问题C）
5. 「宁缺毋滥」替代硬凑 12 条（指控3的正确修法）
6. 次级四项（第三节）

**先量测再说**：尾部质量退化——需要按 index 分组的池内质量数据，llm_runs 现在
不存 response 正文，得先补采样再下结论。

任何改动上线前须过 L3 真机对照（同参数新旧两版各跑一池，判官盲评+同族塌缩率
复测），防止修复自伤——batch 消融那张表就是前车之鉴的反面教材：**这条 prompt
里每一条看似过度的约束背后几乎都埋着一次真机事故，删之前先挖它的墓碑**。

## 附录：修改落地与真机验证（2026-08-24 当日）

改动落在 `_build_raw_idea_pool_messages` author_pitch 臂 + `_parse_raw_idea_records`

（含 3 个新回归测试）。

### 迭代过程中真机抓到的两个新病（都是种词铁律的新形态）

1. **指令词即骨架**（四轮实证，同一结论）：prompt 里点名的要求词被整批复印成
   句式骨架——旧版「今天/少年」12/12，v2a「亲手」11/12+「他要的不是」8/12，
   v2b 换成「宁可…也要」，v2d「主动/一个替…」12/12。措辞怎么改，塌缩只换目标
   不消失：**句法塌缩与场域塌缩同构，是采样结构性质，措辞治不了**。判定为已知
   局限不再打地鼠——seed 句式不出货，下游展开整句重写。
2. **示例即内容**：v2c 里 graft 因果示例「会挖矿→矿越挖越多→变强」被直接抄成
   一条矿工创意；无下限的「宁缺毋滥」一轮只回 4 条。修法：示例改类别式因果链
   （做什么→为什么因此得什么→所以越做越强），产量补下限 8。

### 最终 A/B（同判官同参数，MiniMax-M3 温度 0.82，各两轮独立复测）

| 指标 | 旧版（合并24条） | 新版（合并21条） |
|---|---|---|
| 判官综合（六轴） | 5.72 | **6.38** |
| click_seed（渴望） | 5.88 | **6.67** |
| freshness | 5.33 | **6.33** |
| promise_survival | 5.29 | **6.14** |
| freshness+click 双≥7（可进展开） | 2 | **9** |
| 被动开局（确定性标记） | 0 | 0 |
| 场域互异 | 12/12 | 12/12 |

两轮新版的每一轮都高于两轮旧版的最好一轮（新最低 6.29 > 旧最高 5.85），方向
在全部六轴一致。旧版的典型产出是「替人做X的少年今天遇到怪事」式好奇钩
（12/12 同骨架、零渴望表述）；新版 12/12 有明确的主角主动行动+想赢得的具体
东西，graft 里长出了真实因果桥（「秘传剑谱只认笔迹不认人头，谁落笔谁就是
传承人」）。

未做之事：分批生成（消融证死）、判官大改（只加了 graft 一行）、跨书同质化
（另属采样结构层）。生产级结论仍需整链真机（建书→淘汰赛→展开）跑一本验收，
本验证只覆盖池层。

3. **kernel 里带 `_render_story_logic_gate_rules`**：这不是判据双载，是硬门
   契约前置——三条轴在这里铸死、logline 救援禁止发明事实、三本真书死于
   契约缺席（2026-07-21/22）。反面教材是 prompt 压缩把【章末规则】删了 76%
   再按 ENDING_HOOK_MISSING 毙章。区分标准：**硬杀轴的契约必须前置；判官的
   打分细则不得前置**。

### 负例种词的适用边界（本次排查钉下的新判据）

三处生成端带引号负例，处置各不同：

## 附录六：《吃我一筷》简介逻辑病定案（2026-08-25）

用户报真机简介"语句不通、逻辑不通"（custom-xuanhuan-1787662679）。排查结论：
**生产端造病、审查端失明，两层同时漏**——且最冤的是 premise 里明明有完整机制链
（刻反向引气归元纹→食客夹菜灵气被吸→回流喂自己），是简介层把它弄丢的。

三个实锤根因（全部已修）：

1. **生成端「可以少写」洞**：⑨b 机制保真写着「可以少写，不许改写」——写手把
   机制整个"少写"掉，只剩效果（护体灵气当场炸了），完全合规。修：钉死下限
   （金手指一句话因果必须在前半交代，机制零交代=废稿）+新增⑨d 首现带锚
   （封灶签子/议灶这类凭空实体的源头）。
2. **dangling 检察官逃生门**：教科书级无锚（封灶签子首现即被处置）6 调用全零
   发现——旧反例给了「悬念式留白」无条件豁免，模型把一切无锚自我合理化。
   修：留白豁免必须能逐字引出着落原文，引不出=病。
3. **头号病无轴可诉**：mechanism 轴只查「矛盾」不查「缺位」。修：新增
   effect_unexplained 教学轴（效果无因，单引文病），照「新检测器只挣重生
   和留痕」规矩不杀候选、喂打磨（消费管道 08-23 就建好了，一直在喂空气）。
   另修判官帽 700→1400、500→800（真机 1/6 截断丢发现）。

真机校准（M3，temp 0.25）三轮迭代到干净：
- 病例：dangling 抓到「封灶签子」（0→1）；effect 抓到两处「护体灵气」效果（0→2）
- 负对照（premise 有机制/干净简介）：初版 effect 误报"简略当缺席"~50%，两针
  收窄（简略不是病+同句破折号前半就是机制）后连续两轮零误报，病例命中保持

外部模型四条批评的核验：③因果断裂（成立，头号病）②信息密度（成立，同因）
①主语悬空（部分成立，短句分行本身是榜单形态铁律）④语体混搭（弱成立不动，
轻松爽文品类惯例）。
