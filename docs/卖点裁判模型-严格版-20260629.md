## 1. 框架现在是怎么判卖点的（审计结论）
| 层 | 判什么 | 性质 |
|:--|:--|:--|

**关键**：前置 `logline_gate`（读者视角熔断）与 `premise_appeal_judge`（编辑视角终检）**互补不冗余**；但 v1 只有 3 轴，漏了爆款公式里最关键的几条。

## 2. 爆款卖点到底靠什么（调研：中西合流）
**Save the Cat 官方 logline 法**（[来源](https://savethecat.com/tips-and-tactics/how-and-why-to-write-a-good-logline)）：
- **irony / 反差是钩子之核**（"The most important thing for a good logline is irony"）；
- a compelling **mental picture**（能在脑中成像）；
- 锋利的主角 + 原始目标 + 最大冲突。

**番茄/起点爆款公式**（[番茄7逻辑](https://zhuanlan.zhihu.com/p/25748899579)、[套路爽点库](https://zhuanlan.zhihu.com/p/28933770160)、[爽点秘籍](https://blog.csdn.net/2301_79545694/article/details/143189707)、[怎样爆火](https://www.zhihu.com/question/657577142)）：
- **简介 = 背景 + 人物困境 + 矛盾主线 + 人设卖点 + 悬念冲突**；
- **人设反差**（明身份赘婿/外卖员 × 暗身份神王/首富）= 爽点核心；
- **爽感一眼可见**（前三章让读者清楚「图什么」）；
- **差异化**（避开写烂的红海套路）；首句即冲突、章末留钩。

## 3. 升级后的严格裁判模型（7 维 / 两档）
> 单一真源 `config/story_appeal.yaml:logline_gate`；裁决纯函数 `logline_gate.decide_logline_action`。

### 核心命门（hard veto，任一不达标即拦）
| 维(权重) | 高分 | 低分（拦） | 出处 |
|:--|:--|:--|:--|
| **反差张力 22** | 强反差/反常识/期待违背(身份明×暗、恩人即加害者) | 四平八稳、无「咦?」 | Save the Cat irony + 网文人设反差 |
| **点击钩子 18** | 首句即未知/危机，一句就想点 | 开头是设定铺陈，钩子迟到 | 番茄首句冲突 |
| **动机可信 16** | 非做不可、代价收益对等或被逼无选择 | 得不偿失/圣母，不信他会反复做 | 你的反馈 |
| **不可预测 14** | 有铺垫可信的反转/悖论，走向有想象空间 | 一眼望到头(能力→代价→揪凶手) | 你的反馈 |

### 增益维（计入加权总分，可被补偿）
| 维(权重) | 高分 | 低分 |
|:--|:--|:--|
| **情绪承诺 12** | 一眼知道图哪种情绪满足(爽/悬/虐/治愈)且匹配题材 | 说不清图什么、卖"文笔好/世界观大" |
| **差异化 10** | 高概念/新组合，没人这么写 | 命中红海套路(赘婿逆袭/废柴觉醒/系统签到) |
| **具体可视 8** | 能成像的人/事/画面 | 抽象设定罗列、形容词堆砌 |

### 裁决（严格）
- 任一**核心命门 < 2.5** → **REJECT**（根本性硬伤，不予扩充）。
- 任一**核心命门 < 3.5**，或**加权总分 < 3.6** → **REGENERATE**（回炉重写卖点，≤3 次，附逐维 fix）。
- 全部核心 ≥ 3.5 且总分 ≥ 3.6 → **EXPAND**（放行扩充）。
- LLM 不可用 → fail-open 中性 3.7（真放行，绝不无判官误毙）。

## 4. 实测（裁决逻辑 `decide_logline_action`，代表性读者分）
```
【《我替死神签收加班》借命/恩人悖论】 EXPAND  总分=4.23  最弱=情绪承诺
   → 过严格门，但情绪承诺(3.0)是软肋：偏虐/悬、大众爽点盘窄
【赘婿神医回都市打脸(红海套路)】     REJECT  总分=2.92  最弱=差异化
   ✗ 不可预测 1.8 一眼望到头  ✗ 差异化 1.5 红海套路  ✗ 反差 3.0 四平八稳
【少年踏上修炼之路终成强者(抽象)】   REJECT  总分=1.87  最弱=反差张力
   ✗ 反差 1.5  ✗ 点击钩子 1.8(设定铺陈)  ✗ 动机 2.5
```
→ 红海套路稿、抽象无钩稿被**严格拦下**；真高概念稿放行但软肋被点名。这就是「较严格的卡控」。

## 5. 你的卖点该不该改（诚实建议）
当前《我替死神签收加班》是**强 logline（6/7 强）**，过严格门。唯一软肋是**情绪承诺偏窄**（虐+悬+赎罪，非大众爽）。两条路：
- **A 保持高概念定位**：主打「代价流/悬疑」细分，接受盘子小一些但口碑/完读率高——arena 双盲对标该细分爆款验收即可。
- **B 拓宽大众盘**：在卖点里**加一条大众情绪锚**（如把「补遗言」做出阶段性「打脸/反转解气」小爽点，或给主角一个明×暗身份反差），把情绪承诺从 3.0 抬到 4.0+。

我建议 **A**（这本书的力量正在「沉重的两难」，强行加爽点会调性背叛，反被 `tone_consistency` cap 罚）。若你要走番茄大众主线爆款，应换一个**爽点型**卖点重新过这道门。
