# 建书选项不落地（爽文无代价）— 七轮根治记录与验证

日期：2026-08-06
触发：用户报「新建书籍没有严格遵守设定，如爽文无代价」
纪律：`docs/开发与验证标准-feature-lifecycle-20260618.md`

---

## 0. 结论先行

`cost_style=minimal`（建书页「爽文无代价」）从捕获到落地全链断了 **5 处**，另有 **3 处**是修复过程中新暴露的框架缺陷。七次真机建书后，第七本《我一招，夺你功法》首次做到设定完整落地——升级引擎原文写着「代价为零——不是用法越多越弱，而是法越多越强，越用越顺」。

**元病一句话**：生成端可以自由产出验收端必杀的东西；而多数门只给结论不给证据。

---

## 1. 诊断链（每一环都有 file:line 证据）

| # | 缺陷 | 证据 | 性质 |
|---|---|---|---|
| D1 | minimal 指令末句把决定权交还模型 | `ideology_kernel._cost_style_directive`：「至于要不要有代价……由这本书自己的设定决定」 | 真缺陷 |
| D2 | 同一开关在 planner 另有一份翻译，同批被放宽 | `planner._source_bound_cost_rules` | 两处事实 |
| D3 | 整书门 `emotion_cost_free_win` 不知道 cost_style | `whole_book_quality_gate` 全文无 cost_style | 反向自伤 |
| D4 | 淘汰赛零本体校验 | `concept_tournament.py` grep 无 ontology | 真缺陷 |
| D5 | 查重基线含 0 章废壳 | `_recent_core_mechanisms` 只按题材过滤 | 误杀 |
| D6 | 我的修复点名母题词「债/账」 | `test_prompt_pollution_sweep` 拦截 | **我引入** |
| D7 | 代价指令只到商业定位，未达市场/角色/世界观 | `writing_profile.market/.character` 来自独立 LLM 调用 | 真缺陷 |
| D8 | 本体判决面 24 字段修复函数够不着 | `_repair_final_ontology_drift` 无 high_concept 入参 | 结构缺陷 |

**最深的一条**：反母题检测器家族已于 2026-08-02 全线退役（`is_debt_dominated` 等全部 `del text; return False`），但 `_anti_debt_metaphor_guardrail` 的 docstring 仍写着「漂移由输出侧检测器捕获」——**注释描述了一个被拆除的系统**。prompt 侧无禁令 + 输出侧无检测 = 中间真空。拿真实违规文本直测检测器全部返回 False，可当场证实。

## 2. 修复

### 2.1 代价开关（D1/D2/D3/D7）
- 恢复方向性约束，**不恢复类别白名单**（旧版枚举允许类别→修仙世界写成物流公司+门禁杀书）
- **不点名任何母题词**（D6 教训）：「主角的能力可以放心使用：用它不会削弱主角，用得越多也不会越难用。它需要付出什么，永远不是本书的引擎、不是卖点，也不构成某一章的主要内容。」
- 顺带修掉 `external` 档既有的同类缺陷（原文点名「记忆/寿命/身体/关系/地位」）
- 注入 7 处：商业定位 + 市场/角色/世界观 ×(zh/en)。`standard` 档字节不变
- 整书门加 `cost_style` 入参；`minimal`/`external` 不再因「胜利无代价」被判违规

### 2.2 淘汰赛本体优先（D4）
`_prefer_ontology_clean()` 选冠军前降权漂移候选。**只做偏好不做过滤**——全员漂移时原样返回整池（清空候选池会把「需要推一把的书」变成「根本建不出的书」）。闸门本身不放宽。

### 2.3 查重基线（D5）
进入跨书查重前必须有 `ChapterModel` 行，且 fail-open（查不到章节信息时保持原行为，不静默关闭跨书查重）。
⚠️ 运维教训：**清库必须在建书之前**，否则构思期旧壳仍在库中导致自撞。

### 2.4 本体修复覆盖判决面（D8）
high_concept 纳入修复入参与返回值，且**修好的冠军写回 `ctx["high_concept"]` 再重扫**（算了不写回＝修复静默空转）。

### 2.5 可观测性
- 「题材本体漂移」→ 带命中 token
- 画像门只存分数不存原因 → 落库 `persona_gate_evidence`（concerns / high_risk_personas / thresholds）

## 4. 验证

### L1/L2
新增/修改测试文件 6 个，定向回归 152 项全过；全量 `tests/unit` 9202 passed。
过程中打破 7 个既有测试，全部按纪律归因（改测试桩以匹配新契约，非削弱修复）：
- `test_conception_mechanism_dedup` ×5：桩 session 只返 4 元组，我加了第 5 列
- `test_planner_services` / `test_prompt_pollution_sweep`：我的措辞点名母题词（真缺陷，改措辞而非改断言）

关键回归用例（均用真实事故数据）：
- `test_tournament_ontology_preference`：用「阴间挂号处临时工」原文，断言高分漂移候选被降权、全漂移不清空池
- `test_echo_baseline_excludes_unwritten_books`：0 章废壳不算旧书，含 fail-open 用例
- `test_ontology_repair_covers_verdict_surface`：**结构性不变量**——判决面参数集合 ⊆ 修复面参数集合
- `test_cost_style_pure_shuang_wiring`：三档指令均不点名母题词 + planner/kernel 不得漂移

### L3 真机
七次真机建书，逐轮定位不同死因（见 §1）。第七本全链通过：
- 构思三门（本体/回声/种子忠实度）全过
- 设定检查：tags / trope_keywords / writing_profile / commercial_brief / book_design_snapshot + 正文，**零违规**
- 安全网实证：重写 `attempt_index` 封顶 3 → 落 `quality_debt` 显式终态，**无无限循环**；73.9 万 token 产出 6 章（对照：历史事故单循环烧 88 万 token 零产出）

## 5. 待办

- 画像门 `PERSONA_WEIGHTED_SCORE_LOW`：5 章得分 0.49–0.61 稳定低于阈值 0.62。**未调阈值**——窄带分布是系统性偏低而非噪声，调阈值只会让门闭嘴。需拿真实爆款跑该门做校准，库空时无基线。
- AI 味归因终评：等 50 章定稿后统一测（中途测量会踩「草稿仍在变」的假象——第 1 章 8.0 分那一稿一小时后已被替换）。
- 待验假设：低 AI 味是否来自重写深度而非写手 prompt（归因脚本已记录稿数，可做相关性检验）。
