# 故事/大纲/简介 吸引力评估体系 · 功能特性记录与验证报告

> 日期 2026-06-21 | 分支 `feat/story-appeal-evaluation` | 关联：构思/conception、大纲、引流物料
> 遵循《开发与验证标准-feature-lifecycle-20260618》｜ 立项见《故事大纲与简介吸引力评估体系-开发计划-20260621》

## 0. TL;DR
新增一套**故事创意 + 简介点击力**的吸引力评估体系，回答"这个大纲/设定好不好、读者会不会仅凭简介就点进来"。**简介点击力 10 维确定性 gate**（零 token、可复现、零家族偏见）是达标的**硬信号**；**故事吸引力 9 维 LLM 判官**（题材感知、fail-open）提供批评/建议但**仅 advisory**（实测其绝对分不可靠）。orchestrator 合成 `StoryAppealReport` 接进构思：评分入库可审，弱稿触发有界保优 fail-open 重生。全程 soft/additive，未启用字节级不变。
**关键诚实点**：达标线**不是自己拍的**——用 `scripts/calibrate_appeal_against_bestsellers.py` 对**10 本真实爆款简介 vs 6 条烂稿**、并用**跨家族 DeepSeek 判官**校准：确定性 blurb gate 真爆款 vs 烂稿 Δ+12.2（三次运行恒定）、烂稿 0% 误放，据此把门锚在 65；LLM 绝对分因不可靠降为 advisory。原先 MiniMax 自评的 83/85 已证实为同源高估并弃用。

## 1. 背景与根因（file:line 证据）
痛点：系统能产出"结构完整但没人想点"的书——构思期**无任何"脑洞值不值得写/简介勾不勾人"的判定**。
| 缺口 | 证据 |
|:--|:--|
| 构思 review 分从不门控 | `services/conception.py:1232` 出 `overall_coherence_score` 仅写日志 |
| premise/synopsis/title 裸串无契约 | `conception.py:66` `ConceptionResult`；裸 `str` |
| 简介"点击吸引力"零评估 | 简介仅 `conception.py:1337` 生成；全仓无 judge 给简介打吸引力分 |
| 卖点/标签只有格式门 | `book_listing.py:776` `validate_book_listing_profile` 只查"填没填全" |

## 2. 设计与落地
### 2.1 原则
soft/additive；未启用零变化（`enabled:false`→`ConceptionResult` 字节级不变）；题材一等公民 + generic 兜底（`genre_taxonomy.canonicalize`，每题材同一把尺→"每题材达标"可达）；单一真源 `config/story_appeal.yaml`；判官缓存复用 `outline_llm_judge`；输入封顶。

### 2.2 改动清单
| 文件 | 类型 | 职责 |
|:--|:--|:--|
| `config/story_appeal.yaml` | 新增 | 单一真源：9+10 维 rubric、gating、grades、达标线、题材词库(generic+8 题材)、平台简介字数带 |
| `src/bestseller/domain/appeal.py` | 新增 | frozen dataclasses + `to_dict` |
| `src/bestseller/services/blurb_appeal_gate.py` | 新增 | 确定性 10 维简介点击力（零 token） |

### 2.3 评分维度
- **故事 9 维**：概念强度/卖点(gate<2→pass) · 新颖度/差异化(题材) · 冲突/赌注 · 情绪价值/爽感(题材) · 钩子/悬念(gate<2→consider) · 代入/主角 · 可持续(long;gate<2→consider) · 读者匹配(gate<2→consider) · 结构节奏。一票否决（gating）防文笔等弱相关项托高烂点子。
- **简介 10 维（确定性）**：卖点三要素 · 钩子强度(首句≤30字+三选二) · 差异化 · 反模板(AI腔黑名单) · 结尾留钩非剧透 · 题材信号一致 · 代入具体化 · 情绪强度前置 · 形容词节制 · 长度排版。
- **11 心理触发器**：信息缺口/缺口适度/高唤起/代入锚/愿望预告/损失张力/in-medias-res/悬念栈/反常/兑现可信。
- **达标线（竞品锚定，见 §3.竞品校准）**：`blurb≥65`（确定性 blurb gate——可复现、零家族偏见、对真实竞品校准过的唯一稳定信号）。**LLM premise 绝对分仅 advisory，不参与达标硬判**（实测其绝对值不可靠，一句 prompt 改动即从给烂稿 88 荡到给凡人 38）；严谨的故事质量门是对真实竞品 pairwise 盲评胜率（下一步）。同一把尺，所有题材。

### 2.4 运行时数据流
`conception finalize → (premise,synopsis,title,tags) → evaluate_story_appeal[blurb_gate(确定性)+premise_judge(LLM,题材context)] → StoryAppealReport`；若 grade≤floor 则注入改进反馈重跑 finalize（≤2 次，保优，fail-open）→ `ConceptionResult.story_appeal` → `web/server.py` 入 metadata.conception_artifacts。

- **B 强/弱判别（确定性 blurb gate，零 LLM）**：强 blurb84 vs 弱 blurb53 + 精准 findings（缺冲突代价/AI腔9处/无情绪）→ **PASS ✅**。

### ⭐ 竞品锚定校准（防"意淫"，`scripts/calibrate_appeal_against_bestsellers.py`）
针对"凭什么说达榜单级 / 对标了什么竞品 / 怎么保证不是自评"——用**真实爆款简介**（诡秘/凡人/斗破/赘婿/全职/大奉/亵渎/庆余年/诛仙/师兄，n=10）vs **烂稿/AI稿**（n=6），过①确定性 blurb gate（零 LLM、零家族偏见）②premise 判官走**跨家族 DeepSeek**（≠MiniMax 写手，去同源高估）。实测：

| | blurb 均（确定性） | premise 均（DeepSeek） | 达标率（blurb≥65） |
|:--|:--|:--|:--|
| 真爆款 n=10 | **68.4** | 60.1 | 60%（现代强简介全过；老牌朴实简介落选） |
| 烂稿 n=6 | **56.2** | 55.6 | **0%（零误放）** |
| 分离度 | **Δ+12.2（三次运行恒定）** | Δ+4.5（小且跳动） | — |

**结论（诚实）**：
1. **确定性 blurb gate 是可信信号**——真爆款比烂稿高 +12.2、三次运行恒定、零家族偏见、烂稿 0% 误放；65 是"零误放"下的竞品锚定门。
2. **LLM premise 绝对分不可信**——跨家族 DeepSeek 都把"剧透无悬念"打 81.9、把凡人打 47，一句 prompt 改动即大幅跳动 → **降级 advisory，不参与达标**（与 [[benchmark-arena-closure-plan]] LitStyle 绝对分结论一致）。
3. **原先的 83/85 是 MiniMax 同源自评，确属高估**；改用竞品锚定 blurb 门后，新书按**判官无关**的确定性 blurb 分判：玄幻75/都市79/纯爱69 → 均≥65 **达标**（与真实现代爆款同档）。
4. 落选的 4 本真爆款是老牌作品的**朴实简介**，按今日番茄点击标准本就偏弱——系统如实判低，是诚实非 bug；再降门会放进烂稿（设定堆砌63.9/空泛62.8），故 65 已是最优分离点。

### 开新书验证（真实 LLM 设计，竞品锚定判定）
`scripts/demo_story_appeal_real_books.py` 真实 MiniMax 跨题材跑 conception：玄幻《我能看见天道裂缝》、都市《维度契约》、纯爱《共情陷阱》。按竞品锚定的**确定性 blurb 门**：blurb 75/79/69 → **3/3 达标**（与真实现代爆款同档，且为判官无关、可复现的判定）。

玄幻样例（真实模型，非打桩）：书名《我能看见天道裂缝》；卖点=穿越者觉醒【天道熔炉系统】十倍效率、每次突破燃烧寿元、能看见天道规则裂缝。
- 达标判定（硬）：**确定性 blurb 75/100 ≥65 → 达标 ✅**（判官无关、可复现）。
- advisory：检测到 5 心理钩子（T3/T4/T5/T6/T7）；LLM 判官给出可执行批评——代入感 3.5（系统太抢戏、主角性格模糊）、新颖度 3.8（系统+代价已成套路）——证明 advisory 批评非橡皮图章，能指出真实短板（注：MiniMax 自评的故事总分 83 属同源高估，仅参考）。

### ⭐⭐ 故事质量硬门：对真实爆款 pairwise 盲评胜率（`scripts/verify_appeal_arena.py`）
绝对分不可信，故事质量改用**相对盲评**（与正文层 `benchmark_arena` 同款）：候选简介 vs **同题材真实爆款简介**，双盲、**位置交换**、**跨家族 DeepSeek** 判官，每对判两次只取一致胜，win-rate=(win+0.5·tie)/pairs。模块 `services/premise_appeal_arena.py`，参照集 `config/appeal_reference_blurbs.yaml`，门槛 `arena.story_winrate_min=0.45`。实测：

| 候选 | vs 真实爆款 win-rate | 判定 |
|:--|:--|:--|
| 玄幻《我能看见天道裂缝》(真实生成) | **0.88**（胜斗破/完美世界/赘婿，平诡秘） | ✅ |
| 都市《维度契约》(真实生成) | **0.75** | ✅ |
| 纯爱《共情陷阱》(真实生成) | **0.50** | ✅ |
| 烂稿/AI稿（负控） | **0.00**（输给全部 4 本真爆款） | ✗ 正确拒绝 |
| 凡人修仙传（真爆款 sanity） | **0.38**（vs 同行居中，非 0 非 1） | 合理 |

**三条 sanity 全部成立** → 这是可信的故事质量硬门：①烂稿对真爆款 0% 胜（干净拒绝）；②真爆款 vs 同行居中（没被高估也没被打死）；③真实生成新书 0.50–0.88 与真爆款**同档或更强**。方法本身去同源高估（跨家族）、去位置偏（交换）、稳定（相对判断）。
> 成本：每本 ~N×2 次判官调用，故作**按需验收门**（不进每次构思）；构思期的便宜硬门是确定性 blurb gate。L1 12 测（含内容感知假判官验证胜率两端 + 位置偏置被中和到 0.5）。

## 4. 结果与结论
吸引力评估从"无"到"端到端可用、接进构思、且达标判定全部锚定真实竞品"。两道竞品锚定的硬门：
1. **简介点击力**（构思期，便宜）：确定性 blurb gate，门槛 65 由真爆款 vs 烂稿校准（烂稿 0% 误放、Δ+12.2、零家族偏见、可复现）。
2. **故事质量**（验收期）：对真实爆款简介的 pairwise 盲评胜率（跨家族 DeepSeek、位置交换），门槛 0.45；真实生成新书 0.50–0.88、烂稿 0.00、真爆款 sanity 0.38。
LLM 绝对分一律仅 advisory（已证不可信）。三层验证 + 竞品校准 + 真机零副作用全过，未启用零变化。**"凭什么算达标"从自评彻底变成了对真实竞品、跨家族、去偏、可复现的判定。**

## 6. 一句话总评
**好故事/好简介的"吸引力"可被拆成确定性可判的简介点击力 + 题材感知的 LLM 故事判官，用 gating 防弱相关项托分、用确定性 floor 防 LLM-down 自伤、用有界保优重生闭环——评估不只是打分，而是接进生产、让弱稿真正变好。**
