## 1. 诊断（代码证据）

四路审计确认："账/欠账"旧书味的既有六轮清剿守卫（`tests/unit/test_cross_book_leakage_guard.py`）全绿且已进运行容器，但真残留在**守卫扫描盲区**——守卫只扫 `src/bestseller` + `config/`（`test_cross_book_leakage_guard.py:26-28,88,158`），债务专项仅覆盖 `story_appeal.yaml`/`hook_mechanisms`/`novel_categories`/5 个 planner 文件，**不含** `data/methodology_sources/`、`config/reference_corpora/`、`config/motif_library.yaml`、`narrative_tree.py`。

这些是**题材中性的生成/规划面**（对所有题材、所有书生效），其债务词面会随方法论块/参考语料/母题/规划节点树进 prompt，触发"LLM 把 avoid 词当素材吸收"失效模式（`conception.py:1463` 记录）。

区分：**题材隔离**的债务（wuxia 侠义债 / relationship 情感债 / urban 人情债与商战应收账款）经 `resolve_*(genre)` 只在本题材渲染，合法，不清不网。

## 2. 计划（soft/additive、单一真源）

内容清洗 = 中文正文去金融化换喻，**保留英文代码耦合标识符**（`debtor`/`creditor`/`promise_debt`/`debt_clearance`/`scorecard.foreshadowing_debt`/`category:debt`——它们被 `methodology_application_gate.py:64-65,299-300` 与 `methodology_health.py:277,486` 引用；英文对中文债务漂移影响小）。守卫只扫**中文**债务字符（故意排除裸"账"以放过 `账号/账户`）。

## 4. 三层验证

**L1 单测（含非空转证明）**：守卫 6 测全绿（`pytest tests/unit/test_cross_book_leakage_guard.py --no-cov` → 6 passed）。非空转/RED-before 模拟：把 6 条**原污染串**喂新守卫 token，全部 HIT（`债`/`催收`/`账清`/`结算`/`账本`/`债`），证明守卫有效非空转。

**L2 回归**：受影响模块 231 测全绿，零失败——
- 直接相关 37 绿：narrative_tree / platform_character_debt_assets / methodology_book_corpus / methodology_application_gate / methodology_book_distillation / methodology_book_selector / benchmark_corpus / story_design_grammars / 守卫。
- 扩大 188 绿：methodology_compiler / prose_prompt_experiment / material_lifecycle / methodology_abc_harness / methodology_bridge / planner_methodology_injection / benchmark_capability_audit / distillation_book_aggregator / ideology_library / novel_categories。
- 快照核查：`tests/fixtures/` 无我改动串，无快照回归。

**L3-lite 真实渲染（零 token / 零副作用）**：调 `compile_methodology(stage=...)` 真实编译方法论 prompt 块（拉取 plova/pcd 卡），grep 16 债务字符——conception（2487 字）/ review（3429 字）块 **CLEAN**，零命中。加全量源文件复扫（`data/methodology_sources`/generic/suspense/motif/narrative_tree 均 clean）+ YAML/PY 解析校验全 OK。

> 说明：完整 live-docker 真机书跑（构思→大纲装配→grep 债务）为**合并前收尾门**；本次以"源文件零残留 + 真实编译块零残留 + 231 测零回归"三重证据链替代，text-only 清洗残留风险极低。
