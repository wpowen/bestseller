## 1. 诊断（代码证据）

用户痛点"写爽文时系统强行加代价（失去身体/地位/记忆）"的最刚性、最字面来源=**意识形态内核 `cost_system`**：
- `domain/ideology.py:396-401` + `CostLaw._normalize:250-253`：LLM 不给代价时**自动补默认**「获得力量/真相 → 关系/记忆/寿命/身份之一」——这行兜底就是"失去记忆/身体/关系"的字面出处。
- `domain/ideology.py:545`（render 硬段）：每本书 prompt 恒定出现"### 代价系统（力量/真相/救赎都必须付费, 不可白给）"，且意识形态内核是**全书思想脊柱**，注入 world/volume/chapter 每层 prompt——覆盖面最大、权威最高。

## 2. 计划（soft/additive、单一真源、no-op 字节级不变）

三档 `cost_style`：`standard`(现状) / `external`(代价外置，主角不自损，由对手/世界/资源承担) / `minimal`(极简，服务爽感)。选 external/minimal 时**换代价方向**而非零代价（零代价会连环撞简介判官/番茄硬毙/意识形态判官三处标尺，需全面重标定，风险高——本档设计用"代价外置"达成"主角一路爽"且逻辑仍自洽）。默认 standard → 全链 prompt 逐字节不变。

**关键架构**：把 `cost_style` 存到 `IdeologyKernel` 自身（字段），使**派生**与**渲染**两处都能读到，无需分别穿参。意识形态脊柱的 render 硬指令（external 档"禁止削减主角记忆/身体/关系/寿命/地位"）权威高于下游次级代价面（章位置代价账/钩子等价交换），故控住脊柱即控住主信号。
