## 1. 段 1 — 一句话卖点（四要素齐 + 可下沉循环）
> **修正记录**：初版「折自己寿命救陌生人 + 攒命救妹妹」被卖点闸门判 REJECT——动机得不偿失（折寿救陌生人图不到对等回报）、且「能力查案→代价递增→揪凶手」一眼望到头。修正核心：把动机换成**借来的命（停手即死）**（最硬动机，绝不得不偿失）+ 把妹妹折叠进**恩人悖论**（救他的人＝可能被他所害的人），让走向不可预测。
- **人**：李拙，26 岁，市殡仪馆夜班工，三年前火灾里「本该死的第七人」。
- **欲（双动机，都极硬）**：① **活下去**——停手就被「补录」回死亡名册；② 查清三年前那场火里，妹妹之死究竟是**替他牺牲**还是**被他所害**。
- **阻（绕不开）**：补出的遗言线索步步指向「是他亲手把妹妹骗进火场」；折寿黑市与「收尾人」盯着这条借来的命。
- **代（不可逆）**：每补一单欠下新债；越查越逼近「我配不配活」这个无法回避的问题。
- **下沉校验**：卖点 → 前三章立规则(七小时/借命/停手即死)+妹妹名字钩子 → 十章内第一次「补全遗言反而毁掉一个活人」的道德反噬 → 一卷高潮「折寿黑市」。✅ 能下沉。

## 2. 段 2 — 故事发动机
- **欲望三层**：表层＝活下去并洗清「我害死了妹妹」的嫌疑；深层恐惧＝「真相是我亲手害死了唯一替我去死的人」；最终不能失去＝把自己当成一个还值得活的人。
- **want ≠ need**：want＝证明自己无罪、留住这条借来的命；need＝接受真相、学会「有些命还不清，只能背着走」，不再用别人的命续自己的命（终局逼他在二者间选一次）。
- **核心循环（可复 30×，对手/场景/代价每轮变形）**：
  1. 触发：一具新遗体浮出未尽工单，最后一行空着；
  2. 行动：七小时内查清死者没说完的那句话（解谜单元）；
  3. 奖励：补全→死者回魂七小时说完话 + 掉落一块指向妹妹真相的碎片；
  4. 投入：折走等长寿命 + 死者生前遗留的一个新麻烦缠上他（仇家/秘密/债）。
- **三循环变体**（防单调，交替排布）：升级循环（能力：补一句话→改一段记忆→重写整张工单，代价从寿命扩到记忆与身份）/ 关系循环（与刑警苏晚、同事老周、被救者家属结成债与信任）/ 谜团循环（妹妹工单「签收人＝他自己」逐层揭开）。
- **每胜有代价（铁律）**：每救一人，①寿命刻度可见减少 ②牵出一个更大的麻烦。无一次「免费的善」。

## 3. 段 3 — 前期设定 · 第一章
- **题材正确的爽点**：「他用自己的命，换一个陌生人对家人说完最后一句话」的悲壮解气 + 每解一单＝解开一块妹妹真相的智性爽。**禁**打脸/跪地/碾压（与立意背叛）。
- **黄金三章合约**：
  - 第一屏（≤30 字钩）：凌晨三点，殡仪馆，第七具遗体睁开了眼。
  - 第一章：李拙发现补全遗体头顶那行字能让死者多活七小时——同时手背浮出一行**倒数的寿命刻度**（第一次可见代价）；章末，他在次日待运名册上看见一个名字：李昭（妹妹）。
  - 前三章：立规则（七小时/折寿）、立循环（第一单完整跑通）、立钩子（妹妹名字+签收人悬念）。

### 5.3 章契约样例（卷一 ch1，**因果链合规**：choice≠desire、cost≠pressure、function 非通用）
- 压力（pressure）：第七具遗体睁眼、工单最后一行空着，逼他七小时内补全。
- 欲望（desire）：他想确认这能力是不是真的。
- 选择（choice，≠desire）：补上那句「妈，门口的灯我修好了」。
- 可见行动（visible_action）：死者回魂、对赶来的母亲说完那句话；李拙手背浮出寿命刻度。
- 状态变化（state_change）：从「以为自己只是普通夜班工」→「知道自己握着生死与寿命的权柄」。
- 代价（cost，≠pressure）：第一次知道，救人是用自己的命付的——少了七小时。
- 章功能（function，非「推进卷一主线」）：立『七小时/折寿』规则 + 投妹妹名字钩子。
- 下一章新欲望（next_desire）：名册上「李昭」二字让他决定——无论代价，撬开妹妹的工单。

## 10. ★一句话卖点【前置】闸门（本轮新建：先判卖点，不过不扩充）
> 起因：初版卖点确定性尺子打 85.5（recommend），但那只是**词形/结构**分——它**看不出**「折寿救陌生人」的动机得不偿失、也看不出「能力查案→代价→揪凶手」一眼望到头。**结构高分 ≠ 真有吸引力。** 故新建一道**读者视角语义闸门**，放在世界观/角色/卷章扩充**之前**：卖点不过 → 不予扩充（用户核心思路）。

### 10.1 三条读者命门（LLM 读者判官，语义；确定性器测不了）
| 命门 | 打什么 | 专治 |
|:--|:--|:--|
| 点击欲 click_desire | 只看这一句，读者想不想点开 | 平淡/像分类标签 |
| 动机可信 motivation_credibility | 主角驱动可信吗、会不会得不偿失让人出戏 | **折寿救陌生人却图不到对等回报** |
| 不可预测 unpredictability | 能否一眼望到头、有没有想象不到的反转 | **能力→代价→揪凶手 套路** |

裁决：任一命门 `<reject_floor(2.0)` → **REJECT 不予扩充**；`∈[2.0,3.0)` → **REGENERATE 回炉重写卖点**（≤3 次）；全 `≥3.0` → **EXPAND 放行**。LLM 不可用时 fail-open 到中性 lean-pass，绝不无判官误毙。

### 10.2 本例裁决对比（用真实裁决逻辑 `decide_logline_action` 跑出）
```
【旧卖点·折寿查案】 裁决=REJECT  最弱维=motivation_credibility
  ✗ [动机可信|硬伤 1.9] 主角动机得不偿失/牵强，读者不信他会这么做
  ✗ [不可预测|偏弱 2.1] 套路可一眼望到头，意料之中、无惊喜
  → 重写动机使其【非做不可】：代价与收益对等，或把主角逼到没有退路
  → 埋一个读者预判不到的反转/悖论，打破「能力→代价→揪凶手」闭环
【新卖点·借命/恩人悖论】 裁决=EXPAND  三命门全过 → 放行扩充
```
（旧/新命门分数为**读者判官代表性打分**，用于演示裁决逻辑；真机 LLM 复核需 live 凭证。裁决规则本身已 L1 全测。）
