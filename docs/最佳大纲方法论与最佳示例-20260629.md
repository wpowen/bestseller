# 最佳大纲方法论 与 最佳大纲示例

> 2026-06-29　配套《大纲能力-质量根因与增量优化计划-20260629》。
> 这份文档回答 /goal 的两个终点问题：**「最好的大纲方法论长什么样」**与**「一份达行业顶尖的大纲示例长什么样」**。
> 方法论不是又一份说教，而是把 24 章教材收敛成 **5 段「先验级联」+ 每段一张可验收的卡 + 代码落点**。

## 一、最佳大纲方法论：5 段先验级联（Gated Cascade）

**核心原则（对掉当前管线的形状）：**
> **能不能钩人 → 先验；钩得住 → 才逐层下钻。任何一层不过闸门，回到上一层重做，不往下展开。**
> 这正是用户 #1：「一句话卖点若无法吸引，则无需展开细节」。当前管线是「先一次性展开 5 件事，末端给简介打结构分」——形状相反，是无聊与不连贯之源。

每一段都遵循同一条验收律（取自教材 ch3/ch4 的「编辑验收三问」）：
1. **是否让读者比上一行更想知道后果？**（吸引）
2. **人物是否因此背上新的限制 / 债务 / 风险？**（代价）
3. **删掉它，后续因果是否崩？**（结构必要性，不是装饰）

---

### 段 1 — 一句话卖点 / Logline（教材 ch3）★最高优先级闸门
**产物（四要素，缺一不可）：**
`某种人 + 想要某目标 + 被某具体阻力压制 + 必须付出某不可逆代价`

**验收闸门（不过 → 重写 logline，不进段 2）：**
- [ ] 一句话能说清「人 + 欲 + 阻 + 代」，且这句**本身**就钩人（含 What-if / 反常识 / 即时冲突）。
- [ ] 阻力**绕不开**（不是「努力就能解决」）。
- [ ] 代价**不可逆**（赢了也得失去点什么）。
- [ ] 能下沉成**可复 30 次的核心循环**（见段 2），不是只够写三章的点子。
- **反例**：「少年成长为强者」（无阻无代）/「文笔好、世界观宏大」（卖设定不卖处境）。

**代码落点**：`premise_appeal_judge.concept_strength`（已有，9 维之一，gate_below=2）。
**当前缺口 → 计划 Phase 2**：concept_strength 现为 advisory（`premise_min=0`），且 logline 不是一等产物（散落 `logline/one_liner/reader_promise`）。应升为一等 `StoryCore` 并在段 1**先验**；用相对 arena（`premise_appeal_arena`，唯一可信绝对信号）作软门。

---

### 段 2 — 故事发动机 / Story Engine（教材 ch4 + core_loop）
**产物：**
- **欲望三层**：表层想要 / 深层恐惧 / 最终不能失去的东西。
- **want ≠ need**：他**想**要的（外在目标）≠ 他真正**需要**学会的（内在转变）。
- **核心循环（上瘾四步，可复 30×）**：触发(欲望)→行动(可执行)→奖励(随机/递进)→投入(沉没成本/代价)；对手、场景、奖励、代价不断变形。
- **三种循环变体**：升级循环 / 关系循环 / 谜团循环（教材 ch3 操作流程②）。
- **每胜有代价**：每次奖励都登记一项损失（身体/关系/名誉/资源/道德/时间）。

**验收闸门（不过 → 回段 1 或重设发动机）：**
- [ ] 换场景能把核心循环重复 30 次而不枯竭？
- [ ] 每个「奖励」都绑定一个「代价」？（无代价的胜利只加战力、不加重量）
- [ ] want 与 need 有张力，且 need 会在终局逼主角做一次真正的抉择？

**代码落点**：方法论 `core_loop.addiction_model`（config/writing_methodology.yaml，已定义）。
**当前缺口 → Phase 2**：`series_engine` 现在是**规划之后回填（REACTIVE）**，核心循环只 advisory，从不对大纲校验。应在段 2 **前置**生成并校验「循环可复用 + 胜负有代价」。

---

### 段 3 — 前期设定：爽点·题材·用户诉求·第一章（教材 ch1/ch2/ch8/ch9）
**产物：**
- **题材-读者-平台三角**：写给谁、满足哪一种核心情绪（爽感/悬念/关系/成长/治愈/探索）。
- **题材正确的爽点**：用本题材的高唤起事件，不借别题材的情绪词（悬疑爽在解谜+代价张力，不是打脸）。
- **第一章三层**（开篇三层验收表）：第一屏抓人 / 第一章建立目标+规则+第一次可见代价 / 前三章兑现黄金三章合约。

**验收闸门：**
- [ ] 第一屏 30 字内有强钩（冲突事件 / 反差 / 谜面），不是平铺设定句。
- [ ] 第一章末有**可见损失或倒计时**（不是预告「将会很精彩」）。
- [ ] 爽点情绪与题材一致（用 `genre_emotion_exemplars` 自检）。

**代码落点**：`opening_three_function_gate` / `opening_golden_chapter_gate` / `blurb_appeal_gate`（情绪/钩子命门）。
**本次已修（Phase 3 切片）**：`blurb_appeal_gate.emotion_charge` 原为**爽文词表关键词计数**，把「靠处境/两难/代价承载情绪」的 show-don't-tell 简介误判为 0 情绪并被命门（<3.0）封顶 78、倒逼重生成廉价堆词稿——**这是「简介让人不想读」的直接机械成因**。已加**具身情绪通道**（两难/切肤/迫近/骇异四类结构信号，题材中立），取 `max(关键词, 具身)` 只升不降。证据见 §三。

### 段 4 — 长篇规划：世界观·筹码·钩子（教材 ch5/ch6/ch7/ch10）
**前置条件：段 1-2 闸门已过（发动机健全）才做这一段。**

**产物：**
- **世界观（差分推演）**：现实基线 + premise 公理扰动 → 推导每个维度被**迫**改变了什么 + 故事所站的断层线。（不套题材默认世界，同题材两本必不同。）
- **筹码四压表**（ch6）：时间 / 身体 / 社会 / 道德，四种压力同时施加并可叠加。
- **钩子账本**（ch7）：3-7 个并行钩子（信息差 / 威胁 / 欲望 / 截止 / 谜团），每个有生命周期与预期回收章。
- **五层规划骨架**（ch10）：premise → book spec → story bible(不变事实库) → volume plan → chapter contract。

**验收闸门：**
- [ ] 世界观每条规律都能追到 premise 公理（不是题材贴皮）？
- [ ] 任一时刻至少 3 个活跃钩子，且各有预期回收章？
- [ ] 四压里至少 3 压同时在场？

**代码落点**：`world_model_deriver`（✅ 已对，差分推演接地）/ `hook_ledger` / `book_spec.series_engine`。
**当前缺口 → Phase 3/4**：钩子 `expected_payoff_by_chapter` 无人校验是否真埋；`_ensure_complete_profile` 在 world 稀疏时用 genre preset 兜底 → 通用化。

---

### 段 5 — 结构构建：雪花递进 + 场景/伏笔嵌套（教材 ch11/ch12/ch13/ch14/ch15）
**产物（逐层下钻，每层对上层取证）：**
1. **锁五个固定点**（ch11）：开局状态 / 终局状态 / 主角核心弱点 / 最大对手 / 最终代价。
2. **卷 synopsis**：每卷主目标·核心对手·能力升级·关系变化·卷末新威胁（保 20% 发现空间）。
3. **章 beat**：每章一个 causal_contract——压力→**欲望(≠选择)**→选择→可见行动→状态变化→**代价(≠压力)**→下一章新欲望。
4. **场景五字段卡**（ch12）：目标·阻碍·行动·结果·反应。
5. **伏笔回收账本**（ch14）：每个 setup 标注预期 payoff 章；反转用「三线索」法（ch15，原来如此≠天降设定）。

**验收闸门：**
- [ ] causal_contract 是**因果链**而非字段堆（choice≠desire、cost≠pressure、function 非「推进卷X主线」通用兜底）？
- [ ] 每条伏笔有预期回收章，且回收时改变读者对前文的理解？
- [ ] target_emotion 由 premise/题材决定（不是按章号位置默认「爽/紧张」）？

**代码落点**：`scene_beat_planner` / `foreshadowing` / `outline_field_enrichment`。
**当前缺口 → Phase 3/4**：`outline_field_enrichment._fill_causal_contract` 现在**复制字段**（choice=desire、cost=pressure）凑满 8 项即过闸门 → 「看着完整、实则空壳」= 逻辑不通；`_fill_target_emotion` 按章号位置兜底（黄金章=爽）premise-blind；规划是 flat batch 无雪花下钻。

## 二、最佳大纲示例（完整走完 5 段级联）

> 题材：都市怪谈 / 悬疑 / 代价流（男频偏向，亲情张力）。
> 选它做范本，因为它能把「高概念 + 不可逆代价 + 可复 30 次的循环 + 切肤亲情」一次性示范全。

### 段 1 — 一句话卖点
> **殡仪馆夜班工能看见遗体头顶『没说完的最后一句话』，补全它就能让死者回魂七小时——代价是从自己寿命里划走等长的时辰；他攒命只为撬开三年前火灾里没跟他说完话的妹妹的工单，却发现妹妹工单的签收人，写着他自己的名字。**

- 人：殡仪馆夜班工（小人物 + 隐秘异能）
- 欲：救回三年前没说完话的妹妹
- 阻（绕不开）：每次用能力都折自己的寿命 + 妹妹工单签收人是他自己（真相威胁）
- 代（不可逆）：寿命一去不回；逼近真相＝逼近「妹妹之死是否与他有关」

### 段 2 — 故事发动机
- **欲望三层**：想要＝救活妹妹；深层恐惧＝「有些话永远来不及说」；最终不能失去＝自己还活着、还能记得妹妹。
- **want ≠ need**：want＝用命换妹妹复活；need＝学会接受告别、放下「用命换命」的执念。
- **核心循环（可复 30×）**：①触发：一具新遗体浮出「未尽工单」，最后一行空着 →②行动：七小时内查清死者没说完的那句话并补全 →③奖励：死者回魂一次 ＋ 一条指向妹妹真相的碎片 →④投入：划走对应寿命 ＋ 欠下死者生前留下的一个新麻烦（仇家/秘密/未竟事）。
- **三循环变体**：升级（能力从「补一句话」→「改一段记忆」→「重写整张工单」，代价从寿命扩到记忆与身份）；关系（与刑警、同事、被救者家属结成债与信任）；谜团（妹妹工单「签收人＝他自己」逐层揭开）。
- **每胜有代价**：每救一人，寿命刻度可见减少，且牵出一个更大的麻烦缠上他。

### 段 3 — 前期设定 / 第一章
- **题材-读者诉求**：悬疑+代价流读者要的是**智性解谜 + 道德两难 + 亲情张力**，不是打脸爽。
- **爽点（题材正确）**：「他用自己的命，换一个陌生人对家人说完最后一句话」的悲壮与解气感；解开一单＝解开一块妹妹真相的爽。
- **第一章三层**：
  - 第一屏：凌晨三点，殡仪馆，第七具遗体睁开眼，头顶浮出灰色工单，最后一行空着。
  - 第一章：李拙发现补全那句话能让死者多活七小时——同时自己手背浮出一行倒数的寿命刻度（第一次可见代价）。
  - 章末钩子：他在次日待运遗体名册上，看见一个名字——他妹妹。

### 段 4 — 长篇规划
- **世界观（差分推演，接地 premise 公理「未说完的话滞留遗体七小时」）**：
  - 殡仪馆夜班＝隐秘「回魂窗口」管理者，形成地下职业链；
  - 出现「代写遗言」黑市与「折寿掮客」（寿命成可交易货币）；
  - 法律对「七小时内死者证词」无定义 → 灰色取证地带；
  - 断层线：主角站在「救人/惜命」「真相/逃避」的双重断层上。
- **筹码四压**：时间（七小时窗口＋自身寿命倒数）/ 身体（寿命刻度肉眼可见地减）/ 社会（殡仪馆规则、折寿黑市、刑警怀疑他制造命案）/ 道德（救陌生人值不值得折寿；妹妹真相若是他的错，敢不敢面对）。
- **钩子账本（并行 5）**：信息差（妹妹工单签收人是他）/ 谜团（妹妹之死真相）/ 截止（寿命刻度）/ 威胁（折寿掮客盯上他）/ 欲望（救活妹妹）。

### 段 5 — 结构构建（雪花递进 + 伏笔嵌套）
- **五固定点**：开局＝殡仪馆夜班＋第七具遗体；终局＝面对妹妹工单真相、做出「救她/放手」的终极抉择；核心弱点＝用命换命的执念、逃避告别；最大对手＝管理所有未尽工单的「收尾人」（也可能是他自己）；最终代价＝要么耗尽寿命复活妹妹却让她活在愧疚里，要么放手让妹妹真正安息。
- **卷骨架（前 3 卷示意）**：
  - 卷一「七小时」：单元案立规则＋立代价，卷末——发现妹妹名字在名册上。新威胁：折寿掮客登场。
  - 卷二「折寿黑市」：能力升级到「改一段记忆」，关系线（刑警搭档）建立；卷末揭示——三年前火灾当晚，他也在场，且记忆缺了一段。
  - 卷三「签收人」：谜团逼近，每解一单都更接近「妹妹是替他签的单」；卷末抉择前夜。
- **章 beat 因果链范例（卷一 ch1，合规版 causal_contract）**：
  - 压力：第七具遗体睁眼、工单最后一行空着，逼他在七小时内补全；
  - **欲望**：他想确认这能力是真的（≠选择）；
  - 选择：补上那句「妈，门口的灯我修好了」；
  - 可见行动：死者回魂、对赶来的母亲说完那句话；
  - 状态变化：手背浮出寿命刻度，少了七小时；
  - **代价**（≠压力）：他第一次知道，救人是用自己的命付的；
  - 下一章新欲望：名册上的妹妹名字让他决定——无论代价，他要撬开妹妹的工单。
- **伏笔嵌套**：ch1 埋「签收人＝他自己」→ 卷二揭「火灾当晚他在场、记忆缺段」→ 卷三 payoff「妹妹替他签了单/他当年用一次回魂救了别人、代价是没能救妹妹」——回收时改变读者对 ch1 的全部理解（ch15 反转律）。
