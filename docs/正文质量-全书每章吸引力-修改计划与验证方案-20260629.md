# 正文质量 · 全书每章吸引力 · 修改计划与验证方案（2026-06-29）

> 目标：把已验证的开篇方法论扩展为**位置感知的全书方案**——不只前三章，**后续每一章都达到爆款水准**。
> 全程**大模型真实生成 + pairwise 盲评打分**验证，最终产出一套"最吸引人的方法论 + 提示词方案"。
> 框架代码不动，旁路实验（工具 `scratchpad/ladder_runner.py` / `genre_recipe.py`）。

## 一、现状（已验证资产）
- 标准层：红线硬门（确定性·自测过）+ claude pairwise 盲评（VOTES=5，可读性/追读/**开篇前300字抓人**三种判官）。
- L1 通用核心：OPEN开篇炸点律 / CV调性 / B4动机前置 / B2机制落地 / B7起承转合 / A1章末强钩 / A2情绪高点 / A3信息差递进。
- L2 题材触发：GS爽点(男频80%) / GE情感(女频80%) / GT设定亮相(半通用)。
- L3 反面禁忌：不逐条朗读规则/不灌输设定/不写清单。
- 已验证：**全在第1章/开篇**。开篇炸点 O1/O3=100%、O2=80%。

## 二、缺口（本次要补）
**所有验证都在"第1章"。"后续每一章保持高水准"是未验证维度。** 中段章节的挑战与开篇不同：
1. 无首因新鲜感——读者已知世界/主角，开篇炸点律(OPEN)不适用中段。
2. 注水/塌方——重复、不推进、节奏拖。
3. 一致性——人物状态/能力等级/世界规则/时间线/地点不能矛盾（医院→亦庄类错误）。
4. 养成获得感——长期读者要看到主角阶段性成长。

## 三、位置感知方案（核心设计）
正文按**章节位置**用不同开篇/节奏策略，其余通用块与题材触发块不变：
| 位置 | 章头策略 | 专属块 |
|------|---------|--------|
| 开篇章(ch1-3) | 炸点前置(OPEN) | OPEN + 黄金三章留存 |
| 中段章(ch4+) | 快速重入(接上章钩子立刻推进) | **M系列(本次验证)** |
| 高潮章 | 兑现+反转 | (后续) |

**M 系列中段章块（待验证，prose 可控）：**
- M1 快速重入：章头3句内接住上一章钩子并立刻推进，不复述前情、不重新铺垫。
- M2 单章必推进(反塌方)：章末局面必须不可逆变化（获得/失去/暴露/升级/新威胁），不回原点。
- M3 章内爽点+钩节奏：每章至少兑现一个小爽点或解一个小悬念，并埋一个新钩。
- M5 成长可见：主角实力/处境/关系相比前文有可见阶段性进展。
- （M4 一致性：属**大纲/状态层**职责——正文只能忠实使用给定状态；见 `大纲能力` /goal 线。）

## 四、验证计划（大模型实测打分）
**判官升级**：新增"中段追读判官"——立场="已追读到第50章的读者，读完这章会续读还是弃书"，看重新进展/爽点钩子/节奏/一致。
**测试场景**：构造一个中段（ch50）场景：一句话前情提要 + 本章设定 + 人物/世界状态，喂给写手。
**流程**：base = L1通用核心(去OPEN，因非开篇) + 题材触发 → 测 M1/M2/M3/M5 边际增益（forward selection，VOTES=5，N=2），≥66%加/≤34%删。
**跨章留存补测**：判官读"第1章末 + 第2章头"判是否无缝追读（验证章衔接）。

## 五、阶段
- P1 中段章 M 系列验证（男频，本次执行）→ 得中段章触发集。
- P2 跨题材复跑（怪谈/女频/玄幻）确认 M 块通用。
- P3 跨章留存测量（ch1→ch2 衔接）。
- P4 合成**位置感知 × 题材自适应**最终方法论 + 提示词方案 + 各位置最优正文样本。
- P5 多模型可迁移复核（kimi/claude）。

## 六、产出
- 位置感知配方生成器（genre_recipe 升级：入参加 chapter_position）。
- 全书各位置最优正文样本（开篇/中段/高潮）。
- 最终方法论文档 + 打分证据表。
- 回写框架前走 L1/L2/L3+A/B。

## 七、诚实约束
- 单写手 minimax-m3 + N=2 有噪声，结论方向性，关键用户终审 + 多模型复跑。
- 一致性(M4)非 prose-prompt 能根治，依赖大纲状态层。
- minimax 限流严重，每批 15-25min，分批后台跑。
