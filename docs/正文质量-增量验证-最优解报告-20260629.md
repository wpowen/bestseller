## 一、流程闭环（已建立）
1. **标准层（TDD 测试先行）**：红线硬门（确定性·单元测试级）+ 盲评 rubric（pairwise·集成级）+ 用户金标准（验收级）。
   - 红线门自测全过；体检真实样本能精准抓到 ver2/ver3 的 markdown 泄漏与过短，且校准掉了"章节标题/钩子比喻/！！！情绪"等误报。
2. **验证层**：greedy forward selection + 边际增益 + 拖累检测，三轮逐步加料。
3. **决策层**：边际胜率 ≥66% 加、≤34% 删、其间持平不加、单加正/叠加负则删。

## 三、加料收益曲线 / 核心机理
```
L0 裸  ──(+B1+B2+B4: 大幅提升)──►  核心  ──(+B7: 小幅提升)──►  最优解
                                          └─(+B5/B8/B3/B9: 持平或拖累)─► 变差
```
**拐点在第 4 块**。核心机理：**轻量"要求类"块（调性/机制落地/动机/结构）正增益；重型"结构化方法论指令"（爽点四拍、解谜闭环、设定灌输、世界观锚点）会把正文写成"规则清单/设定集/说明书"，叠加即拖累。** 这就是现有框架"堆一大堆方法论反而 AI 味重、看不懂"的根因——不是块没道理，是**当成硬指令逐条塞、且加过了拐点**。

## 四、最优解（可回写框架的融合配方）
把 4 个有效块融合成一段精炼写作要求（避免逐条罗列本身造成的"清单感"），并把被删块转成反面提醒：
```
【正文写作要求】
- 番茄/七猫规则怪谈、手机碎片阅读：短句直给、画面感强、节奏快，让人一口气读下去。
- 开篇就立住主角"非做不可"的私人紧迫理由（具体、私人、紧迫），第一时间代入。
- 任何能力/道具/超自然机制，第一次出现就用一句大白话点破"是什么+干啥+代价"，
  不堆术语、不假设读者已懂设定。
- 全章有完整起承转合：开篇异常→中段升级→临界反转→结尾留扣，每拍都有可见的局面变化。
切忌（否则必变说明书）：逐条朗读规则、灌输世界观设定、把"爽点四拍/解谜步骤"写成清单。
```
最优配方样本（红线门全过）见 `output/prose-review/ladder-optimal.html` 的 `best` 标签。

## 五、诚实的局限
- **判官噪声**：B5 两轮矛盾（67%→20%）；pairwise reason 偶有 A/B 指代错位。结论为**方向性**，需用户人眼终审（HTML 已备）。
- **单模型**：目前只在 minimax-m3 验证，最优配方需在 kimi/claude 复跑确认可迁移。
- **N 小**：N=2、VOTES=5；关键块（尤其 B5/B6/B9 持平区）若要定稿需加大采样。

## 六、追读吸引力轮（第二维度：从"看得懂"升级到"想看下一章"）
判官换成**追读驱动力**（"读完有多迫不及待想点开下一章"），在最优配方 B1+B2+B4+B7 上测吸引力块：

| 吸引力块 | 追读增益 | 判定 |
|----------|---------|------|
| A1 章末强钩（停最痛处+一句话能复述的迫近威胁） | 100% | **加**（副作用：压缩正文→需配字数下限）|
| A2 情绪高点兑现（最强情绪点集中写透） | 100% | **加** |
| A3 信息差递进（解小谜即抛更大谜） | 100% | **加** |
| A4 主角爽感（解气反击） | 60% | 持平·不加（**题材洞察**：怪谈/悬疑靠悬念+情感，不靠爽点）|

**追读维度的 pairwise 比可读性维度稳得多**（章末钩子具体可比，判官理由高度一致）。
**核心洞察**：A1/A2/A3 全靠把**大纲已有的钩子素材**（亡母侧脸/泪痣/失忆代价/身份反转）兑现到极致。
→ **正文层的吸引力 = 把大纲的钩子写到极致；追读天花板由大纲的钩子/冲突/欲望设计决定。**

吸引力增强配方（在最优解上叠加）：`B1+B2+B4+B7 + A1+A2+A3`（A1 需搭配字数下限保护）。
待验证：A1/A2/A3 三者叠加是否互拖累（需 round5）；跨章追读测量（现为单章代理）；多模型可迁移。
