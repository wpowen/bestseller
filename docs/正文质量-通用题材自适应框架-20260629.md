# 正文质量 · 通用题材自适应框架（题材→触发策略）

> 目标：一套能支撑不同题材/设定的通用正文配方框架。通用块全局生效，题材触发块按题材开关，
> 反面禁忌全局抑制。每个题材的触发集由盲评实验（forward selection + 追读判官）验证得出。
> 方法与工具沿用 `正文质量-增量验证工程流程-20260629.md` 与 `scratchpad/ladder_runner.py`。

## 一、三层块架构
**L1 通用核心（题材无关·always-on）** —— 已在怪谈题材验证为正增益，假设跨题材通用：
- CV 调性：番茄/七猫平台网文、手机碎片阅读，短句直给、画面感强、节奏快
- B4 动机前置：开篇立"非做不可"的私人紧迫理由
- B2 落地律：任何专名/能力/设定，首次出现一句大白话点破"是什么+干啥+代价"
- B7 完整起承转合：开篇异常→中段升级→临界反转→结尾留扣
- A1 章末强钩：停在最痛处+一句话能复述的迫近威胁（配字数下限）
- A2 情绪高点兑现：最强情绪点集中写透
- A3 信息差递进：解一个小谜立刻抛更大的谜

**L2 题材触发块（按题材开关）**：
- GS 爽点打脸：羞辱压迫到顶点→身份/实力反转→旁观者即时反应，给解气的爽
- GE 情感核弹：具体细节+克制对白戳情绪软肋，催泪/揪心
- GT 设定亮相：世界观/金手指首秀眼前一亮但点到为止，不解说体系
- （悬疑/怪谈的"悬念"已由 L1 的 A3 覆盖；A4 解谜清单类已证拖累，不用）

**L3 反面禁忌（always-on·负向约束）** —— 来自拖累块发现（B3/B8/B5/B9）：
- 切忌逐条朗读规则、灌输世界观设定、把"爽点四拍/解谜步骤"写成清单 → 否则变说明书

## 二、题材 taxonomy + 触发映射（假设，待验证）
| 题材 | 代表 | L2 触发块假设 |
|------|------|--------------|
| 悬疑/怪谈 | 规则怪谈 | （L1 的 A3 即可）→ **已验证**：A1/A2/A3=100%，A4 爽感=60%持平 |
| 男频爽文 | 都市赘婿/打脸 | GS（爽点打脸）为命脉 |
| 男频升级 | 玄幻修仙 | GS + GT（设定）|
| 女频情感 | 现代言情/古言 | GE（情感核弹），GS 应低/负 |
| 科幻/末世 | 末世求生 | GT + GS |

## 三、触发机制（通用框架运行方式）
```
题材标签 → 查触发映射表 → 拼装 prompt：L1 通用核心 + 选中的 L2 触发块 + L3 反面禁忌
```
新题材接入：只需在映射表登记其 L2 触发集（用本流程跑一轮 forward 验证即可得出）。

## 四、验证计划
对每个代表题材：base = L1 通用核心，用追读判官测 L2 候选块（GS/GE/GT）的边际增益，
≥66% 触发、≤34% 抑制、其间持平。汇总成题材→触发映射表（第五节，随实验填充）。

## 五、验证结果（四题材，追读判官 VOTES=5，base=L1通用核心）
| 题材 | GS 爽点 | GE 情感 | GT 设定亮相 | 该题材触发集 |
|------|--------|--------|------------|------------|
| 悬疑怪谈 | 60% 持平 | (A2/A3 内含) | — | **仅 L1**（悬念由 A3 承载）|
| 男频爽文·赘婿 | **80% ✅** | 40% 持平 | 80% ✅ | **L1 + GS + GT** |
| 女频言情 | 40% 持平 | **80% ✅** | 80% ✅ | **L1 + GE + GT** |
| 玄幻升级 | 60% 持平 | 60% 持平 | 60% 持平 | **仅 L1**（核心已足够；专属"修炼碾压"块待细化）|

**铁证**：GS 男频 80%↔女频 40%；GE 女频 80%↔男频 40%——题材触发不同策略成立。
**洞察1**：GT(设定亮相·点到为止) 在男/女频均 80% = 半通用（身份/背景揭示助追读），但与 L3"不灌输设定"靠"点到为止"区分。
**洞察2**：玄幻三块全持平 → 当一句话设定本身爽点/冲突够强时，L1 通用核心(含 A1A2A3)即足够，不必硬加触发块。
**洞察3**：怪谈不需要 GS(爽点)——情绪由 A2/A3 的悬念+情感承载，验证了"题材决定吸引力杠杆"。

## 六、最优解产物
- 通用配方生成器：题材 → L1+L2(触发)+L3 的 prompt。
- 各题材最优解正文样本（报告附）。
- 多模型可迁移复核。
