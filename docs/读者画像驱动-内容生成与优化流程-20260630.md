# 读者画像驱动 · 内容生成与优化流程（2026-06-30）

> 病根（实例 custom-xuanhuan-1782808679）：系统不锚定"写给谁"，生成出程序员脑回路的黑话简介——
> 普通男频读者看不懂(99%划走)、懂的程序员挑逻辑且嫌没爽感(1%也弃)，双输。
> 修复主线：**题材→读者画像→按画像生成→模拟该群体读者评分→不达标则按画像改/换题材**。

## 一、调研锚定（维度1·4）
- 番茄/七猫=免费下沉、男女略男多、两头大(青少年+40-50)、千人千面分层；起点男频老白挑剔、晋江女频。
- 男频题材=都市/玄幻/科幻/仙侠/系统升级；女频=现代/幻想/古代言情、甜宠/豪门总裁/重生复仇居前。
- 题材⇄读者画像**强关联**：定了题材，基本就定了人群、知识面、爽点、雷点、对标书。
- 来源：北大番茄调研报告 / 2024网络文学蓝皮书 / 知乎各平台受众画像（见对话 Sources）。

## 二、读者画像机制（维度2）—— `scratchpad/genre_persona.py`
`ReaderPersona`：channel(男/女频) + who + demographics + **knowledge(知识面)** + **fantasy(核心爽点)**
 + click_triggers + turnoffs(雷点) + benchmarks(对标) + **hook_formula(钩子公式)** + persona_judge_role。
`resolve_persona(genre, sub_genre, tags)` → 按关键词命中路由男频/女频画像。
流程顺序：**先题材维度 → 设定/脑洞 → 叠加读者画像 → 生成简介/钩子/正文**（画像是硬锚，不是事后过滤）。

## 三、模拟读者判官（维度3）—— `scratchpad/persona_judge.py`【已验证】
判官角色扮演目标题材的真实读者（如"28岁三线城市外卖小哥、初中文化、用番茄看免费爽文解压、看书名+简介3秒决定点不点"），
输出 `{click, score, why, fix}`——**按目标群体视角量"吸不吸引点击"**，并给出该读者口气的改进建议。
**真机验证**（逆袭从怪谈开始，男频判官 N=3）：
| 版本 | 想点分 | 会点 |
|------|--------|------|
| A 原黑话版(生产实际) | 2.3 | 0/3 |
| B 去黑话版 | 8.7 | 3/3 |
| C 画像定向爽文版 | 8.3 | 3/3 |
判官自动复现用户判断（"看不懂直接划走"+"把灵码编辑器换成能秒懂的"），证明这把尺子有效。

## 四、一句话钩子优化（维度5）
按画像 hook_formula 写：男频=可代入底层主角+憋屈处境+立刻能爽的承诺(金手指/逆袭/打脸，全大白话零专名)；
女频=可代入女主+戳心情感引爆点(背叛/重生/被弃)+情绪承诺(打脸渣/被偏爱/复仇翻盘)。
不达标(persona judge 低分) → 按 fix 反馈重写；若反复不达标 → 提示该脑洞/题材定位有问题，建议换设定。

## 五、闭环（维度1-6 串起来）
```
题材+频道 → resolve_persona(画像) ──┐
脑洞/设定生成 ───────────────────┤→ 注入画像(知识面/爽点/雷点/钩子公式) → 生成简介+一句话钩子
                                  │
            ┌─ 确定性闸门: 新读者可懂度(已落地,黑话过载封顶60)
评分 ───────┤─ 模拟读者判官: 该群体会不会点(score/click/fix)  ← 本次新增、已验证
            └─ 不达标 → 按画像fix重写(有界) → 仍不达标 → 标注题材/脑洞定位问题
达标 → 按画像扩充设定/正文(接 genre_recipe 位置感知正文方法论)
```
