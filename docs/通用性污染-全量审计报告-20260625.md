# 通用性污染 · 全量审计报告（2026-06-25）

> **核心病根**：本框架是**通用**小说框架，但多处把**单本书的私货内容**或**单一题材的套路**焊进了**对每本书都生效的通用层**，导致"当前在写的书/某个题材"污染所有书 → 同质化。6 个并行审计 agent 逐层只读核验，file:line 为审计时实际行号。

## 病根分三类
- **(A) 单本书私货泄漏**：某本书的人名/地名/专名（镜债/铜钱/青囊/三短一长/林正淳/守镜人）被烘焙进通用 prompt/gate/scorer。
- **(B) 单题材套路当全题材默认**：某个题材的招式（侦探取证开局 / HR招聘成长 / 钻规则漏洞 / 男频打脸爽点）被设成**所有书的默认/fallback**。
- **(C) 模板/库过窄或聚类**：品类原型只有1-2个、反转模板一律某一招、机制库对某题材聚类。
