# 人物体系设计方案 · 2026-11-07

用户要求：人物要像真实的人，有性格、脾气、口头禅、缺陷和完整背景，单独设计。本文先查现状，再讲“一个人怎样才算立得住”，最后给出方案和验收办法。只是方案，没有改代码。

## 一、现状（Evidence）

查了 `engine/data/q1_schemas.yaml`、`engine/bookengine/q1_extract.py`，以及《借兽之暖》（第 39 条试写书）和 eval-33《每借一剑》的正文。

**1. 字段有，但很薄。**
- 圣经里每个人有 desire/fear/flaw/bottom_line/voice/growth_end/goal，主角另有 personality_tags/catchphrase/never_do。
- prompt 规定“每条角色字段 ≤40 字”，所以人物是十来个短标签，不是一个人。
- 反派在 `antagonists` 表里只有 name/tier/stage/exit 四个字段。

**2. 写手拿不到其中最有个性的几项。**
- 写每章时，传给写手的人物卡（`q1_extract.py:context`）只包含：
  - identity/voice/gender/address/aliases；
  - active_desire/personality_tags/never_do/desire/fear；
  - 当前状态。
- **flaw（缺陷）、catchphrase（口头禅）、bottom_line（底线）、growth_end（成长终点）从来不传给写手。**
- 结果：两本书 21 个人物，圣经里写了 11 句口头禅，正文出现 **0 次**。

**3. 能传的也常被删掉。**
- 人物卡总长超过 1500 字就开始删字段，最先删的是配角的性格和欲望。
- 《借兽之暖》50 章里，被删的次数如下：

| 被删字段 | 章数 |
|---|---|
| current | 21 |
| desire | 21 |
| fear | 21 |
| personality_tags | 14 |
| active_desire | 14 |
| never_do | 7 |

- 第 20 章连主角自己的 desire 和 fear 都被删了。

**4. 写得具体的说话方式能落地，写得抽象的落不了地。**
- 陆初棠的 voice 写的是“慌时连说三个成交”，eval-33 正文里“成交”出现了 25 次。
- 石彦棕的 voice 是“情绪上来会拍桌骂人”，正文里一个“老子”都没有。
- 顾冬岚的 voice 是“紧张时会拿冷话遮掩关心”，落地了一部分，比如“闭嘴，留点力气。”。

**5. 反派几乎没写出来。**
- 《借兽之暖》里，敖杉予只在 4 章出现，名字一共出现 6 次。
- 裴洛翡只在 3 章出现，名字一共出现 6 次。
- 韩晏竹出场 9 章，名字一共出现 17 次。
- 圣经给每个反派写了缺陷和说话方式，正文里基本看不到。
- eval-33 的外部评审说反派“全是冷着脸逼问的工具人”，和这个现象一致。

**6. identity 字段被原样搬进正文。**
- 第 1 章首句“他是被逐出驭兽宗的矿镇少年，也是雪耳的契主。”和圣经 identity 一字不差。
- 原因：人物卡里写的是“同位语式身份句”，写手照抄最省事。

**7. 旧框架做过一套八层的“角色立体引擎”（标签 `legacy-final-20261104`）。**
- 八层是：欲望与需要、三层动机、价值红线、刺激反应链、关系记忆、识别符、弱点死穴、声纹。
- 思路有参考价值，但没有证据表明它让书变好看；那套框架整体退化后已归档。
- 这里只借鉴思路，不恢复代码。

**以前踩过的坑（来自项目记忆，必须避开）：**
- prompt 里点名的示例句、要求词，会被整批复印成句式骨架（四轮实验定案）。口头禅如果写成“每章都要用”，就会变成机械复读。
- 正文 prompt 越堆方法论越差：裸模型赢过塞满规则的版本。把八层档案整块塞进每章 prompt，大概率变坏。
- 判官打分不能代替读者，有效的是相对盲评。

## 二、一个人怎样才算“立得住”

读者记住一个人物，靠的不是标签多，而是下面几件事同时成立：

1. **他现在想要一样东西，并且在行动。**
   想要的东西要具体、近期、能被阻挡。光“想变强”不算，“今晚必须把妹妹从矿洞里拖出来”才算。
   更深一层是 want 和 need 的错位：他以为自己要的，和他真正缺的，不是一回事。弧光就是后者慢慢取代前者。

2. **他有一组矛盾，而不是一串形容词。**
   “嘴硬、逞强、护短、怕被抛下”是四个标签；“嘴上最狠的人，却最怕被丢下”是一个人。
   读者能用一句话复述的“A 但 B”，就是人设。

3. **性格在选择里显出来。**
   压力下的取舍才是性格：底线是什么，被逼到哪一步会越过底线，越过后怎么面对自己。
   没有选择的场面，性格只是装饰。

4. **缺陷会真的坏事。**
   “嘴硬”要真的让他得罪了该求的人；“替人做决定”要真的害一次队友。
   缺陷只写在卡上、从不付代价，读者感觉不到这个人。

5. **说话方式是“怎么回应”，不是“什么音色”。**
   怎样算有区分度：
   - 被问到痛处时，他是反问、岔开、沉默，还是用动作代答；
   - 生气时，是变短，还是变冷；
   - 说谎时，是说半句，还是说得太多；
   - 什么话他绝不会说。
   “短促硬朗”是形容词；“被关心时先骂一句再递东西”是能写出来的行为。

6. **他看世界有自己的滤镜。**
   药师进门先看谁在流血，猎人先看退路和风向，矿工先听头顶的石头。
   同一个场景，从不同人眼里看出来的东西不同，这是 POV 正文最自然的“人味”来源。

7. **他有过去，但过去体现在反应里，不靠旁白交代。**
   伤口要有来源事件和触发物：一闻到焦饼味就沉默。触发时才露出来，不靠旁白讲背景。

8. **他在不同人面前是不同的样子。**
   对妹妹软、对同伴硬、对仇人笑，同一个人有几张脸。每对重要关系还有一件“未了的事”，推着关系变化。

9. **有一两个识别符，但用得很省。**
   一个物件、一个小动作、一句口头禅，每隔几章、在固定情境下出现一次。用多了就成复读机，从来不用等于没有。

10. **有生活质感。**
    一个小爱好、一样爱吃的东西、一个无伤大雅的怪癖。这些和剧情无关，却最让人觉得“是个活人”。

11. **有的东西会变，有的东西不变。**
    信念和关系会变，底线和核心脾气不变。变的部分按阶段安排，不变的部分不许写崩。

**反派另外要有：**
- 自己的目标，以及在他自己看来合理的逻辑；
- 和别的反派不一样的压迫方式，有人用规矩压，有人用利诱，有人用你在乎的人；
- 和主角的私人关联；
- 至少一个露出人性的瞬间；
- 一个体面或难看的退场。

**网文还要多两点：**
- 主角要有魅力出口，看他是靠嘴、靠狠、靠脑子还是靠护短给读者情绪价值；
- 每个重要配角至少有一场“名场面”，让读者记住他。

## 三、方案

### 3.1 人物档案：建书时单独生成一步

现在人物卡和圣经挤在一次调用里，每项限 40 字。改为：圣经定下人物名单和定位之后，**单独一步生成人物档案**，每个主要人物一份。档案存成文件，属于书目录里的规划数据。

| 层 | 内容 | 主角 | 核心配角、主要反派 | 次要人物 |
|---|---|---|---|---|
| 人设 | 一句“A 但 B”的矛盾式人设 | ✓ | ✓ | ✓ |
| 欲望 | want / need / 两者的冲突 | ✓ | ✓ | 只写 want |
| 伤口 | 来源事件、触发物、触发时的反应 | ✓ | ✓ | |
| 缺陷 | 缺陷 + 在什么情境下坏事 + 坏成什么样 | ✓ | ✓ | |
| 底线 | 绝不做的事；什么情况会逼他越线 | ✓ | ✓ | |
| 说话 | 回应痛处的方式、生气、说谎、开心各一条行为描述；绝不说的话 | ✓ | ✓ | 一条 |
| 滤镜 | 进入新场景先注意什么（由职业和经历决定） | ✓ | ✓ | |
| 关系 | 对每个重要人物：态度、称呼、未了的事、预定的演变 | ✓ | ✓ | |
| 识别符 | 物件、动作、口头禅各 0–1 个，带出现情境 | ✓ | ✓ | 选一个 |
| 生活质感 | 小爱好、口味、怪癖，选一两样 | ✓ | ✓ | |
| 弧光 | 起点信念 → 每阶段被挑战一次 → 终点；以及哪些不变 | ✓ | 简版 | |
| 反派专项 | 目标与自洽逻辑、压迫方式、与主角的私人关联、人性瞬间、退场方式 | | 反派必填 | |

写法规定：
- 一律写成“他会怎么做”的行为句，不写同位语式的身份句。这样从源头上去掉“他是……也是……”被照抄进正文的可能。
- 不给示例台词，只描述台词的结构，避免示例被复印。
- 称呼的来历、和名字的关系，沿用第 40 条已有的一致性检查。

### 3.2 建书时校验档案

**确定性检查：**
- 必填项齐全；
- 人设句里必须有转折；
- 缺陷必须写出触发情境和后果；
- 关系表的人名必须都在名单里；
- 同一本书里，不同人物的说话方式、压迫方式、识别符不能重复或高度相似。

**一次模型复核**（只挑问题，不打分）：
- “这两个人说话方式能不能分出来？”
- “这个反派和上一个反派压人的方式是不是一样？”
- 有问题就定向重写该人物，不重做整本。

### 3.3 规划：把“性格考验”排进章纲

性格要靠场面显出来，所以排期时就安排：
- 规划每个阶段时，给核心人物各排至少一次**性格考验**：哪一章、哪一场、考验哪一面（缺陷、底线或伤口）。
- 主角的缺陷每阶段至少真正坏事一次，并且有后果。
- 每个重要配角在全书里至少排一场名场面。
- 反派登场的那一阶段，要排出他的压迫方式、私人关联，以及至少一次人性瞬间。
- 口头禅和识别符的出现由规划排期，例如每 5–8 章一次，只放在约定情境里，写手不自由发挥。已有的口头禅次数检查用来兜底。

这和第 39 条的章型节奏用同一套规划校验：先排进章纲，再校验，不合格在规划阶段就改。

### 3.4 写作：每场只给需要的那一片

不把整份档案塞给写手（吸取 prompt 瘦身的教训）。每章只给出场人物的：
- 一句话人设；
- 本场要显的那一面（来自 3.3 的排期）；
- 说话方式里与本场相关的一两条；
- 当前关系状态和未了的事；
- 到期的识别符；
- POV 人物的看世界滤镜。

同时修两处现有问题：
- flaw、bottom_line、到期的 catchphrase 要能传给写手（现在不传）；
- 超长时，人物字段最后才删。先压仪表盘和历史摘要，不能先删人物性格。

### 3.5 写完：人物状态要会变

章后抽取已经有 current 字段。这里补上两件事：
- **关系变化和信念变化**：只记有原文引文的；
- **不变项违背**：做了 never_do 里的事，或者底线写崩了。

每个阶段结束时，对照弧光看人物有没有按计划被挑战。

### 3.6 验收：要像读者那样验

1. **换名盲测**：
   - 从正文抽 20 段对话，抹掉名字和称呼；
   - 让另一家族的模型猜是谁在说话；
   - 猜对率就是“人物有没有区分度”的指标。
   - 先在 eval-33 和《借兽之暖》上测出基线。
2. **人设兑现**：每个核心人物的缺陷、底线、伤口、识别符，在正文里有没有可核引文。没有引文记 Unknown，不算通过。
3. **读者测**：
   - 给外部模型匿名读前 5 章，问“你记住了谁？各用一句话说说他是什么样的人”；
   - 看它复述的和档案里的人设对不对得上。
   - 用户自己读也按这个问题。
4. **A/B**：
   - 同一份圣经，写前 5 章两份：一份旧人物上下文，一份新档案；
   - 跨家族匿名盲评，加换名盲测。
   - 新版胜出才往下推。

## 四、分步落地

| 步 | 内容 | 成本 | 先验证什么 |
|---|---|---|---|
| 0 | 修现有漏洞：缺陷、底线、到期口头禅传给写手；改字段删减顺序；身份句不进上下文 | 小，无新调用 | 在《借兽之暖》圣经上续写或重写 5 章，看口头禅、缺陷有没有出现，换名盲测有没有提升 |
| 1 | 人物档案单独生成，加建书校验 | 每本书多 1–3 次调用 | 两本旧书各补生成档案，人工看是否“像个人”，并检查区分度 |
| 2 | 性格考验和名场面排进章纲，加规划校验 | 不加调用 | 章纲层统计排期覆盖率 |
| 3 | 写作按场景切片，章后抽取关系与信念变化 | 不加或少加 | 5 章 A/B：旧上下文对新档案 |
| 4 | 换名盲测、人设兑现、读者测进入整书体检 | 每本书多几次判官调用 | 先测出两本旧书的基线 |

建议先做第 0 步和第 4 步的基线：便宜，而且能先回答“现在人物到底有多扁”。第 1–3 步每一步都要有 A/B 证据再推进。

## Unknown

- 换名盲测的基线还没测，不知道现在两本书的人物区分度具体多低。
- 档案加厚之后写手能吸收多少，会不会又出现规则太多反而变差，要靠 A/B 才知道。
- 旧框架那套八层引擎当时的实际效果，没有找到可信的对照记录。
